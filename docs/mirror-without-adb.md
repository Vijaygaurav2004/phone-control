## agent-a657f70442b310d52.meta

# Android screen mirror — capture + H.264 pipeline (no adb, no dev options)

`MediaProjection` is the only no-adb path, and it costs you one consent dialog per capture session (the token is single-use from API 34 — you cannot cache it). Everything below is platform-only, Java, compiles against `android.jar` (API 36), runs on API 26+.

Package used throughout: `com.local.mirror`. Zero resources — UI is built in code, notification icon comes from `android.R.drawable`, so `aapt2 link` only needs the manifest.

---

## 1. The ordering rule (read this first)

On **API 34+** there is a hard, circular-looking dependency. The only legal order is:

```
1. Activity: createScreenCaptureIntent() -> startActivityForResult()
2. onActivityResult: got (resultCode, dataIntent)  <- do NOT call getMediaProjection() here
3. startForegroundService(service, extras = resultCode + dataIntent)
4. Service.onStartCommand: startForeground(id, notif, FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION)
5. Service: mpm.getMediaProjection(resultCode, dataIntent)
6. Service: projection.registerCallback(cb, handler)   <- BEFORE step 7
7. Service: projection.createVirtualDisplay(..., codec.createInputSurface(), ...)
```

Things that throw if you deviate:

| Mistake | Throws (API 34+) |
|---|---|
| `getMediaProjection()` while no running FGS of type `mediaProjection` | `SecurityException: Media projections require a foreground service of type ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION` |
| `startForeground(..., FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION)` **before** the user has granted consent (i.e. starting the service speculatively on app launch) | `SecurityException` — the system checks for a valid projection token at `startForeground` time. This is why step 3 must carry the token. |
| Reusing the same consent `Intent` for a second `getMediaProjection()` | `SecurityException` — the token is single-use. Re-prompt. |
| `createVirtualDisplay()` without a prior `registerCallback()` (targetSdk ≥ 34) | `IllegalStateException` |
| Missing `<uses-permission FOREGROUND_SERVICE_MEDIA_PROJECTION>` | `SecurityException` at `startForeground` |
| `android:foregroundServiceType` missing/not `mediaProjection` | `IllegalArgumentException` / `InvalidForegroundServiceTypeException` |
| `startForegroundService()` while the app is in the background (API 31+) | `ForegroundServiceStartNotAllowedException` — safe here because `onActivityResult` runs while visible; start it immediately, don't defer behind a dialog |
| Stopping the FGS while projecting | projection is torn down; `Callback.onStop()` fires |

Also: `startForeground(id, notif, type)` is API 29, so guard it (minSdk 26).

## 3. MainActivity.java — consent only

```java
package com.local.mirror;

import android.Manifest;
import android.app.Activity;
import android.content.Context;
import android.content.Intent;
import android.content.pm.PackageManager;
import android.graphics.Rect;
import android.media.projection.MediaProjectionConfig;
import android.media.projection.MediaProjectionManager;
import android.os.Build;
import android.os.Bundle;
import android.util.DisplayMetrics;
import android.view.View;
import android.widget.Button;
import android.widget.LinearLayout;
import android.widget.TextView;

public class MainActivity extends Activity {

    public static final int PORT = 7001;

    private static final int REQ_CAPTURE = 1001;
    private static final int REQ_NOTIF   = 1002;

    private MediaProjectionManager mpm;
    private TextView status;

    @Override
    protected void onCreate(Bundle b) {
        super.onCreate(b);
        mpm = (MediaProjectionManager) getSystemService(Context.MEDIA_PROJECTION_SERVICE);

        LinearLayout root = new LinearLayout(this);
        root.setOrientation(LinearLayout.VERTICAL);
        root.setPadding(48, 96, 48, 48);

        status = new TextView(this);
        status.setText("Idle");

        Button start = new Button(this);
        start.setText("Start mirroring");
        start.setOnClickListener(new View.OnClickListener() {
            @Override public void onClick(View v) { requestCapture(); }
        });

        Button stop = new Button(this);
        stop.setText("Stop");
        stop.setOnClickListener(new View.OnClickListener() {
            @Override public void onClick(View v) {
                Intent i = new Intent(MainActivity.this, ScreenCaptureService.class)
                        .setAction(ScreenCaptureService.ACTION_STOP);
                startService(i);
                status.setText("Stopped");
            }
        });

        root.addView(status);
        root.addView(start);
        root.addView(stop);
        setContentView(root);

        // Not required for the FGS to run, but without it the ongoing notification is hidden.
        if (Build.VERSION.SDK_INT >= 33
                && checkSelfPermission(Manifest.permission.POST_NOTIFICATIONS)
                   != PackageManager.PERMISSION_GRANTED) {
            requestPermissions(new String[] { Manifest.permission.POST_NOTIFICATIONS }, REQ_NOTIF);
        }
    }

    private void requestCapture() {
        Intent intent;
        if (Build.VERSION.SDK_INT >= 34) {
            // API 34+: pin the chooser to the whole display so the user cannot pick
            // "a single app" — that mode resizes the captured content under you and
            // forces an encoder reconfigure via onCapturedContentResize().
            intent = mpm.createScreenCaptureIntent(
                    MediaProjectionConfig.createConfigForDefaultDisplay());
        } else {
            intent = mpm.createScreenCaptureIntent();
        }
        startActivityForResult(intent, REQ_CAPTURE);
    }

    @Override
    protected void onActivityResult(int req, int res, Intent data) {
        super.onActivityResult(req, res, data);
        if (req != REQ_CAPTURE) return;
        if (res != RESULT_OK || data == null) {
            status.setText("Consent denied");
            return;
        }

        // Real display pixels. Measured here because a Service is not a visual context.
        int w, h;
        if (Build.VERSION.SDK_INT >= 30) {
            Rect r = getWindowManager().getMaximumWindowMetrics().getBounds();
            w = r.width();
            h = r.height();
        } else {
            DisplayMetrics dm = new DisplayMetrics();
            getWindowManager().getDefaultDisplay().getRealMetrics(dm);
            w = dm.widthPixels;
            h = dm.heightPixels;
        }
        int dpi = getResources().getConfiguration().densityDpi;

        Intent svc = new Intent(this, ScreenCaptureService.class)
                .setAction(ScreenCaptureService.ACTION_START)
                .putExtra(ScreenCaptureService.EXTRA_RESULT_CODE, res)
                .putExtra(ScreenCaptureService.EXTRA_RESULT_DATA, data)   // Intent is Parcelable
                .putExtra(ScreenCaptureService.EXTRA_WIDTH, w)
                .putExtra(ScreenCaptureService.EXTRA_HEIGHT, h)
                .putExtra(ScreenCaptureService.EXTRA_DPI, dpi)
                .putExtra(ScreenCaptureService.EXTRA_PORT, PORT);

        // We are visible right now, so the API 31+ background-FGS-start restriction
        // does not apply. Do not postpone this behind another dialog.
        startForegroundService(svc);
        status.setText("Mirroring — connect to tcp :" + PORT);
    }
}
```

The Activity never calls `getMediaProjection()`. It hands the token straight to the service and forgets it.

## 4. ScreenCaptureService.java — FGS, projection, lifecycle

```java
package com.local.mirror;

import android.app.Activity;
import android.app.Notification;
import android.app.NotificationChannel;
import android.app.NotificationManager;
import android.app.PendingIntent;
import android.app.Service;
import android.content.Context;
import android.content.Intent;
import android.content.pm.ServiceInfo;
import android.media.projection.MediaProjection;
import android.media.projection.MediaProjectionManager;
import android.os.Build;
import android.os.Handler;
import android.os.HandlerThread;
import android.os.IBinder;
import android.util.Log;

import java.io.IOException;

public class ScreenCaptureService extends Service {

    public static final String ACTION_START = "com.local.mirror.START";
    public static final String ACTION_STOP  = "com.local.mirror.STOP";

    public static final String EXTRA_RESULT_CODE = "resultCode";
    public static final String EXTRA_RESULT_DATA = "resultData";
    public static final String EXTRA_WIDTH       = "w";
    public static final String EXTRA_HEIGHT      = "h";
    public static final String EXTRA_DPI         = "dpi";
    public static final String EXTRA_PORT        = "port";

    private static final String TAG        = "MirrorSvc";
    private static final String CHANNEL_ID = "mirror.capture";
    private static final int    NOTIF_ID   = 0x4D52;

    private static final int FPS      = 30;
    private static final int BITRATE  = 6_000_000;

    private MediaProjection projection;
    private ScreenEncoder   encoder;
    private StreamServer    server;
    private HandlerThread   cbThread;

    /**
     * Required from API 34 before createVirtualDisplay().
     * Never call super.onCapturedContentResize/VisibilityChanged — those methods do not
     * exist on API < 34 and the super call would be a NoSuchMethodError there.
     */
    private final MediaProjection.Callback projectionCallback = new MediaProjection.Callback() {
        @Override
        public void onStop() {
            Log.i(TAG, "projection stopped by system/user");
            stopSelf();
        }

        @Override
        public void onCapturedContentResize(int width, int height) {
            // API 34+. Fires when the captured content's size changes (rotation, or the
            // user picked a single app). The encoder must be reconfigured: MediaCodec
            // cannot change resolution in place.
            ScreenEncoder e = encoder;
            if (e != null) e.resize(width, height);
        }

        @Override
        public void onCapturedContentVisibilityChanged(boolean isVisible) {
            // API 34+. Optional: pause/resume to save battery when nothing is visible.
        }
    };

    @Override
    public IBinder onBind(Intent intent) { return null; }

    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        if (intent == null) { stopSelf(); return START_NOT_STICKY; }

        String action = intent.getAction();
        if (ACTION_STOP.equals(action)) { stopSelf(); return START_NOT_STICKY; }
        if (!ACTION_START.equals(action)) return START_NOT_STICKY;
        if (projection != null) return START_NOT_STICKY;      // already capturing

        int resultCode = intent.getIntExtra(EXTRA_RESULT_CODE, Activity.RESULT_CANCELED);
        Intent token   = intent.getParcelableExtra(EXTRA_RESULT_DATA);
        int srcW       = intent.getIntExtra(EXTRA_WIDTH, 1080);
        int srcH       = intent.getIntExtra(EXTRA_HEIGHT, 2400);
        int dpi        = intent.getIntExtra(EXTRA_DPI, 440);
        int port       = intent.getIntExtra(EXTRA_PORT, 7001);

        if (resultCode != Activity.RESULT_OK || token == null) {
            Log.e(TAG, "no consent token");
            stopSelf();
            return START_NOT_STICKY;
        }

        // ---- STEP 1: be a foreground service of type mediaProjection FIRST. ----
        ensureChannel();
        Notification n = buildNotification();
        if (Build.VERSION.SDK_INT >= 29) {
            startForeground(NOTIF_ID, n, ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION);
        } else {
            startForeground(NOTIF_ID, n);
        }

        // ---- STEP 2: only now redeem the token. Earlier => SecurityException on API 34+. ----
        MediaProjectionManager mpm =
                (MediaProjectionManager) getSystemService(Context.MEDIA_PROJECTION_SERVICE);
        try {
            projection = mpm.getMediaProjection(resultCode, token);
        } catch (SecurityException se) {
            Log.e(TAG, "getMediaProjection rejected (token reused, or FGS not up)", se);
            stopSelf();
            return START_NOT_STICKY;
        }
        if (projection == null) { stopSelf(); return START_NOT_STICKY; }

        // ---- STEP 3: callback BEFORE createVirtualDisplay (IllegalStateException otherwise). ----
        cbThread = new HandlerThread("proj-cb");
        cbThread.start();
        projection.registerCallback(projectionCallback, new Handler(cbThread.getLooper()));

        // ---- STEP 4: network sink, then encoder + virtual display. ----
        try {
            server  = new StreamServer(port, FPS);
            server.start();

            encoder = new ScreenEncoder(projection, srcW, srcH, dpi, FPS, BITRATE, server);
            server.setKeyFrameRequester(new StreamServer.KeyFrameRequester() {
                @Override public void requestKeyFrame() {
                    ScreenEncoder e = encoder;
                    if (e != null) e.requestKeyFrame();
                }
            });
            encoder.start();
        } catch (IOException e) {
            Log.e(TAG, "pipeline start failed", e);
            stopSelf();
            return START_NOT_STICKY;
        }

        Log.i(TAG, "capturing " + srcW + "x" + srcH + " -> tcp :" + port);
        return START_NOT_STICKY;
    }

    @Override
    public void onDestroy() {
        // Release in this order: display+codec, then the projection, then the socket.
        if (encoder != null) { encoder.stop(); encoder = null; }
        if (projection != null) {
            try { projection.unregisterCallback(projectionCallback); } catch (Throwable ignored) { }
            projection.stop();
            projection = null;
        }
        if (server != null) { server.stop(); server = null; }
        if (cbThread != null) { cbThread.quitSafely(); cbThread = null; }
        if (Build.VERSION.SDK_INT >= 24) stopForeground(STOP_FOREGROUND_REMOVE);
        else stopForeground(true);
        super.onDestroy();
    }

    private void ensureChannel() {
        NotificationManager nm = getSystemService(NotificationManager.class);
        if (nm.getNotificationChannel(CHANNEL_ID) != null) return;
        NotificationChannel ch = new NotificationChannel(
                CHANNEL_ID, "Screen mirroring", NotificationManager.IMPORTANCE_LOW);
        ch.setShowBadge(false);
        nm.createNotificationChannel(ch);
    }

    private Notification buildNotification() {
        Intent stop = new Intent(this, ScreenCaptureService.class).setAction(ACTION_STOP);
        PendingIntent pi = PendingIntent.getService(
                this, 1, stop,
                PendingIntent.FLAG_UPDATE_CURRENT | PendingIntent.FLAG_IMMUTABLE);

        return new Notification.Builder(this, CHANNEL_ID)
                .setSmallIcon(android.R.drawable.ic_menu_camera)   // swap for your own drawable
                .setContentTitle("Mirroring screen")
                .setContentText("Tap Stop to end")
                .setOngoing(true)
                .setCategory(Notification.CATEGORY_SERVICE)
                .addAction(new Notification.Action.Builder(
                        android.R.drawable.ic_menu_close_clear_cancel, "Stop", pi).build())
                .build();
    }
}
```

`PendingIntent.FLAG_IMMUTABLE` is mandatory from API 31. `ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION` is an `int` constant, inlined at compile time, so referencing it is safe on API 26.

## 5. ScreenEncoder.java — VirtualDisplay → MediaCodec → NAL units

```java
package com.local.mirror;

import android.hardware.display.DisplayManager;
import android.hardware.display.VirtualDisplay;
import android.media.MediaCodec;
import android.media.MediaCodecInfo;
import android.media.MediaFormat;
import android.media.projection.MediaProjection;
import android.os.Bundle;
import android.util.Log;
import android.view.Surface;

import java.io.IOException;
import java.nio.ByteBuffer;
import java.util.Arrays;

public final class ScreenEncoder {

    public interface Sink {
        /** Annex-B SPS+PPS for the current encoder configuration. */
        void onConfig(byte[] csd, int width, int height);
        /** One Annex-B access unit. */
        void onFrame(byte[] annexB, long ptsUs, boolean keyFrame);
    }

    private static final String TAG  = "MirrorEnc";
    private static final String MIME = MediaFormat.MIMETYPE_VIDEO_AVC;   // "video/avc"
    private static final int MAX_LONG_EDGE = 1600;   // downscale cap; raise for 1:1

    private final MediaProjection projection;
    private final Sink sink;
    private final int fps;
    private final int bitRate;
    private final int densityDpi;

    private final Object lock = new Object();

    private int srcW, srcH;
    private int encW, encH;

    private MediaCodec     codec;
    private Surface        inputSurface;
    private VirtualDisplay display;
    private Thread         drainThread;
    private volatile boolean running;
    private byte[] lastCsd;

    public ScreenEncoder(MediaProjection projection, int srcW, int srcH, int densityDpi,
                         int fps, int bitRate, Sink sink) {
        this.projection = projection;
        this.srcW = srcW;
        this.srcH = srcH;
        this.densityDpi = densityDpi;
        this.fps = fps;
        this.bitRate = bitRate;
        this.sink = sink;
    }

    public void start() throws IOException {
        synchronized (lock) { openLocked(srcW, srcH); }
    }

    public void stop() {
        synchronized (lock) { closeLocked(); }
    }

    /** Called from MediaProjection.Callback.onCapturedContentResize (API 34+) or on rotation. */
    public void resize(int newSrcW, int newSrcH) {
        synchronized (lock) {
            if (newSrcW <= 0 || newSrcH <= 0) return;
            if (newSrcW == srcW && newSrcH == srcH) return;
            srcW = newSrcW;
            srcH = newSrcH;
            closeLocked();
            try {
                openLocked(srcW, srcH);
            } catch (IOException e) {
                Log.e(TAG, "reconfigure failed", e);
            }
        }
    }

    public void requestKeyFrame() {
        MediaCodec c;
        synchronized (lock) { c = codec; }
        if (c == null) return;
        try {
            Bundle b = new Bundle();
            b.putInt(MediaCodec.PARAMETER_KEY_REQUEST_SYNC_FRAME, 0);
            c.setParameters(b);
        } catch (IllegalStateException ignored) { }
    }

    public void setBitRate(int bps) {
        MediaCodec c;
        synchronized (lock) { c = codec; }
        if (c == null) return;
        try {
            Bundle b = new Bundle();
            b.putInt(MediaCodec.PARAMETER_KEY_VIDEO_BITRATE, bps);
            c.setParameters(b);
        } catch (IllegalStateException ignored) { }
    }

    public int getWidth()  { synchronized (lock) { return encW; } }
    public int getHeight() { synchronized (lock) { return encH; } }

    // ------------------------------------------------------------------ internals

    private void openLocked(int sw, int sh) throws IOException {
        MediaCodec c = MediaCodec.createEncoderByType(MIME);

        MediaCodecInfo.CodecCapabilities caps = c.getCodecInfo().getCapabilitiesForType(MIME);
        MediaCodecInfo.VideoCapabilities vcaps = caps.getVideoCapabilities();
        int[] wh = fit(sw, sh, MAX_LONG_EDGE, vcaps);
        encW = wh[0];
        encH = wh[1];

        MediaFormat f = MediaFormat.createVideoFormat(MIME, encW, encH);

        // Surface input: the ONLY legal color format. Anything else and configure() throws.
        f.setInteger(MediaFormat.KEY_COLOR_FORMAT,
                MediaCodecInfo.CodecCapabilities.COLOR_FormatSurface);
        f.setInteger(MediaFormat.KEY_BIT_RATE, bitRate);
        f.setInteger(MediaFormat.KEY_FRAME_RATE, fps);
        f.setInteger(MediaFormat.KEY_I_FRAME_INTERVAL, 1);          // seconds; 1s GOP

        // Surface input produces frames only when the screen changes. Without this the
        // stream goes silent on a static screen and a late client waits for a key frame.
        f.setInteger(MediaFormat.KEY_REPEAT_PREVIOUS_FRAME_AFTER, 2 * 1_000_000 / fps);

        // These three keys are compile-time String constants, so they inline and are
        // harmless on devices whose encoder ignores them.
        f.setInteger(MediaFormat.KEY_MAX_B_FRAMES, 0);              // no reordering -> low latency
        f.setInteger(MediaFormat.KEY_LATENCY, 1);
        f.setInteger(MediaFormat.KEY_PRIORITY, 0);                  // 0 = realtime

        MediaCodecInfo.EncoderCapabilities ecaps = caps.getEncoderCapabilities();
        if (ecaps != null && ecaps.isBitrateModeSupported(
                MediaCodecInfo.EncoderCapabilities.BITRATE_MODE_CBR)) {
            f.setInteger(MediaFormat.KEY_BITRATE_MODE,
                    MediaCodecInfo.EncoderCapabilities.BITRATE_MODE_CBR);
        }
        // Deliberately NOT setting KEY_PROFILE/KEY_LEVEL: several encoders reject a
        // profile without a matching level, and the default is Baseline/Main already.

        c.configure(f, null, null, MediaCodec.CONFIGURE_FLAG_ENCODE);
        inputSurface = c.createInputSurface();   // must come after configure, before start
        c.start();

        codec = c;
        lastCsd = null;
        running = true;

        final MediaCodec drained = c;
        drainThread = new Thread(new Runnable() {
            @Override public void run() { drain(drained); }
        }, "mirror-drain");
        drainThread.start();

        // Virtual display dimensions MUST equal the encoder's configured dimensions,
        // otherwise the compositor scales into a mismatched buffer and you get garbage.
        int vdDpi = Math.max(1, densityDpi * encH / Math.max(1, sh));
        display = projection.createVirtualDisplay(
                "mirror", encW, encH, vdDpi,
                DisplayManager.VIRTUAL_DISPLAY_FLAG_PUBLIC,   // 0 also works; do NOT use
                                                             // AUTO_MIRROR (privileged perm)
                inputSurface, null, null);
        if (display == null) {
            closeLocked();
            throw new IOException("createVirtualDisplay returned null (projection already stopped?)");
        }
    }

    private void closeLocked() {
        running = false;

        if (display != null) { display.release(); display = null; }   // stop producing first

        Thread t = drainThread;
        drainThread = null;
        if (t != null) {
            try { t.join(800); } catch (InterruptedException ignored) { }
        }

        if (codec != null) {
            try { codec.signalEndOfInputStream(); } catch (Throwable ignored) { }
            try { codec.stop(); } catch (Throwable ignored) { }
            codec.release();
            codec = null;
        }
        if (inputSurface != null) { inputSurface.release(); inputSurface = null; }
    }

    private void drain(MediaCodec c) {
        MediaCodec.BufferInfo info = new MediaCodec.BufferInfo();
        while (running) {
            int idx;
            try {
                idx = c.dequeueOutputBuffer(info, 10_000);      // 10 ms
            } catch (IllegalStateException e) {
                break;                                          // codec released under us
            }

            if (idx == MediaCodec.INFO_TRY_AGAIN_LATER) continue;

            if (idx == MediaCodec.INFO_OUTPUT_FORMAT_CHANGED) {
                // Some encoders deliver SPS/PPS only here, in csd-0 (and sometimes csd-1),
                // instead of as a BUFFER_FLAG_CODEC_CONFIG buffer. Handle both.
                emitCsdFromFormat(c.getOutputFormat());
                continue;
            }
            if (idx < 0) continue;

            ByteBuffer out = null;
            try { out = c.getOutputBuffer(idx); } catch (IllegalStateException ignored) { }

            if (out != null && info.size > 0) {
                out.position(info.offset);
                out.limit(info.offset + info.size);
                byte[] data = new byte[info.size];
                out.get(data);

                if ((info.flags & MediaCodec.BUFFER_FLAG_CODEC_CONFIG) != 0) {
                    emitCsd(data);                              // SPS+PPS, Annex-B
                } else {
                    boolean key = (info.flags & MediaCodec.BUFFER_FLAG_KEY_FRAME) != 0;
                    sink.onFrame(data, info.presentationTimeUs, key);
                }
            }

            try { c.releaseOutputBuffer(idx, false); } catch (IllegalStateException ignored) { }

            if ((info.flags & MediaCodec.BUFFER_FLAG_END_OF_STREAM) != 0) break;
        }
    }

    private void emitCsdFromFormat(MediaFormat f) {
        ByteBuffer b0 = f.getByteBuffer("csd-0");
        ByteBuffer b1 = f.getByteBuffer("csd-1");
        if (b0 != null) b0 = b0.duplicate();     // do not consume the format's own buffer
        if (b1 != null) b1 = b1.duplicate();

        int n = (b0 == null ? 0 : b0.remaining()) + (b1 == null ? 0 : b1.remaining());
        if (n == 0) return;

        byte[] csd = new byte[n];
        int o = 0;
        if (b0 != null) { int r = b0.remaining(); b0.get(csd, o, r); o += r; }
        if (b1 != null) { int r = b1.remaining(); b1.get(csd, o, r); }
        emitCsd(csd);
    }

    private void emitCsd(byte[] csd) {
        if (lastCsd != null && Arrays.equals(lastCsd, csd)) return;  // don't thrash the decoder
        lastCsd = csd;
        sink.onConfig(csd, encW, encH);
    }

    /** Clamp to the encoder's real limits and alignment; aspect preserved. */
    private static int[] fit(int w, int h, int maxLongEdge, MediaCodecInfo.VideoCapabilities vc) {
        float scale = 1f;
        int longEdge = Math.max(w, h);
        if (longEdge > maxLongEdge) scale = (float) maxLongEdge / longEdge;

        int tw = Math.round(w * scale);
        int th = Math.round(h * scale);

        if (vc != null) {
            int maxW = vc.getSupportedWidths().getUpper();
            int maxH = vc.getSupportedHeights().getUpper();
            if (tw > maxW) { th = Math.max(1, th * maxW / tw); tw = maxW; }
            if (th > maxH) { tw = Math.max(1, tw * maxH / th); th = maxH; }

            int aw = Math.max(2, vc.getWidthAlignment());
            int ah = Math.max(2, vc.getHeightAlignment());
            tw = Math.max(aw, (tw / aw) * aw);
            th = Math.max(ah, (th / ah) * ah);

            if (!vc.isSizeSupported(tw, th)) {
                tw = (1280 / aw) * aw;
                th = (720 / ah) * ah;
            }
        } else {
            tw &= ~15;
            th &= ~15;
        }
        return new int[] { tw, th };
    }
}
```

Two points worth stating out loud:

- With surface input you **never** call `queueInputBuffer`/`getInputBuffer`. The compositor fills the surface; calling the input-buffer API throws `IllegalStateException`.
- MediaCodec AVC encoders emit **Annex-B** (`00 00 00 01` start codes), not AVCC length-prefixed. Pass the bytes through untouched; the receiver can feed them straight into its own decoder.

## 6. StreamServer.java — framing + backpressure

Wire format, big-endian, fixed 20-byte header:

```
off  len  field
 0    4   magic   0x56535431  ('V','S','T','1')   <- resync marker
 4    1   type    0 = session info, 1 = codec config (SPS/PPS), 2 = video frame
 5    1   flags   bit0 = key frame
 6    2   reserved (0)
 8    8   ptsUs   (int64, 0 for type 0/1)
16    4   payload length (int32)
20    N   payload
```

- type 0 payload = 16 bytes: `version, width, height, fps` (four int32).
- type 1 payload = Annex-B SPS+PPS.
- type 2 payload = one Annex-B access unit.

Resync: hunt forward for the magic, read the header, then verify that the 4 bytes at `offset + 20 + len` are the magic again (and, for type 2, that the payload starts with `00 00 00 01`). Two consecutive valid headers means you are locked. Then wait for the next type 1 + key frame.

```java
package com.local.mirror;

import android.util.Log;

import java.io.BufferedOutputStream;
import java.io.IOException;
import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.net.ServerSocket;
import java.net.Socket;
import java.util.ArrayDeque;
import java.util.Iterator;

public final class StreamServer implements ScreenEncoder.Sink {

    public interface KeyFrameRequester { void requestKeyFrame(); }

    private static final String TAG = "MirrorNet";

    private static final int MAGIC      = 0x56535431;   // "VST1"
    private static final int HEADER_LEN = 20;
    private static final int VERSION    = 1;

    public  static final int TYPE_SESSION = 0;
    public  static final int TYPE_CONFIG  = 1;
    public  static final int TYPE_FRAME   = 2;
    public  static final int FLAG_KEY     = 0x01;

    private static final int QUEUE_CAP = 10;            // ~1/3 s at 30fps

    private final int port;
    private final int fps;

    private final Object lock = new Object();
    private final ArrayDeque<Packet> queue = new ArrayDeque<Packet>();

    private volatile boolean running;
    private volatile KeyFrameRequester requester;

    private ServerSocket serverSocket;
    private Thread acceptThread, writerThread;

    private Socket       client;
    private OutputStream clientOut;

    private byte[] csd;
    private int width, height;

    public StreamServer(int port, int fps) { this.port = port; this.fps = fps; }

    public void setKeyFrameRequester(KeyFrameRequester r) { this.requester = r; }

    public void start() throws IOException {
        serverSocket = new ServerSocket();
        serverSocket.setReuseAddress(true);
        serverSocket.bind(new InetSocketAddress(port), 2);
        running = true;

        acceptThread = new Thread(new Runnable() {
            @Override public void run() { acceptLoop(); }
        }, "mirror-accept");
        acceptThread.start();

        writerThread = new Thread(new Runnable() {
            @Override public void run() { writeLoop(); }
        }, "mirror-writer");
        writerThread.start();
    }

    public void stop() {
        running = false;
        synchronized (lock) { queue.clear(); lock.notifyAll(); }
        closeQuietly(serverSocket);
        serverSocket = null;
        synchronized (lock) { closeClientLocked(); }
        joinQuietly(acceptThread);
        joinQuietly(writerThread);
    }

    // ------------------------------------------------------------- Sink (encoder thread)

    @Override
    public void onConfig(byte[] newCsd, int w, int h) {
        synchronized (lock) {
            csd = newCsd;
            width = w;
            height = h;
            if (client != null) {
                queue.addFirst(new Packet(TYPE_CONFIG, 0, 0L, newCsd));
                queue.addFirst(sessionPacketLocked());
                lock.notifyAll();
            }
        }
        KeyFrameRequester r = requester;
        if (r != null) r.requestKeyFrame();
    }

    @Override
    public void onFrame(byte[] annexB, long ptsUs, boolean keyFrame) {
        boolean needKey = false;
        synchronized (lock) {
            if (client == null) return;

            if (queue.size() >= QUEUE_CAP) {
                // Network is slower than the encoder. Throw away every queued frame
                // (keep session/config), ask for a fresh IDR, and resync from there.
                for (Iterator<Packet> it = queue.iterator(); it.hasNext(); ) {
                    if (it.next().type == TYPE_FRAME) it.remove();
                }
                needKey = true;
                if (!keyFrame) {
                    // Drop this one; the requested key frame restarts the stream cleanly.
                    KeyFrameRequester r0 = requester;
                    if (r0 != null) { /* request outside the lock below */ }
                } 
            }
            if (!needKey || keyFrame) {
                queue.add(new Packet(TYPE_FRAME, keyFrame ? FLAG_KEY : 0, ptsUs, annexB));
                lock.notifyAll();
            }
        }
        if (needKey) {
            KeyFrameRequester r = requester;
            if (r != null) r.requestKeyFrame();
        }
    }

    // ------------------------------------------------------------- network threads

    private void acceptLoop() {
        while (running) {
            Socket s = null;
            try {
                s = serverSocket.accept();
                s.setTcpNoDelay(true);          // latency over throughput
                s.setSoTimeout(0);
                s.setSendBufferSize(512 * 1024);
                attach(s);
            } catch (IOException e) {
                if (running) Log.w(TAG, "accept failed", e);
                closeQuietly(s);
            }
        }
    }

    private void attach(Socket s) throws IOException {
        OutputStream out = new BufferedOutputStream(s.getOutputStream(), 64 * 1024);
        synchronized (lock) {
            closeClientLocked();                 // single viewer; newest wins
            client = s;
            clientOut = out;
            queue.clear();
            if (csd != null) {
                queue.add(sessionPacketLocked());
                queue.add(new Packet(TYPE_CONFIG, 0, 0L, csd));
            }
            lock.notifyAll();
        }
        KeyFrameRequester r = requester;
        if (r != null) r.requestKeyFrame();      // new client needs an IDR to start decoding
        Log.i(TAG, "client " + s.getInetAddress());
    }

    private void writeLoop() {
        byte[] header = new byte[HEADER_LEN];
        while (running) {
            Socket s;
            OutputStream out;
            Packet p;
            synchronized (lock) {
                while (running && (client == null || queue.isEmpty())) {
                    try { lock.wait(200); } catch (InterruptedException ie) { return; }
                }
                if (!running) return;
                s = client;
                out = clientOut;
                p = queue.poll();
            }
            if (s == null || out == null || p == null) continue;

            try {
                putInt(header, 0, MAGIC);
                header[4] = (byte) p.type;
                header[5] = (byte) p.flags;
                header[6] = 0;
                header[7] = 0;
                putLong(header, 8, p.pts);
                putInt(header, 16, p.payload.length);
                out.write(header, 0, HEADER_LEN);
                out.write(p.payload, 0, p.payload.length);
                out.flush();
            } catch (IOException e) {
                Log.w(TAG, "client write failed", e);
                synchronized (lock) {
                    if (client == s) closeClientLocked();   // don't kill a newer client
                }
            }
        }
    }

    private Packet sessionPacketLocked() {
        byte[] b = new byte[16];
        putInt(b, 0, VERSION);
        putInt(b, 4, width);
        putInt(b, 8, height);
        putInt(b, 12, fps);
        return new Packet(TYPE_SESSION, 0, 0L, b);
    }

    private void closeClientLocked() {
        closeQuietly(clientOut);
        closeQuietly(client);
        client = null;
        clientOut = null;
        queue.clear();
    }

    // ------------------------------------------------------------- helpers

    private static void putInt(byte[] b, int o, int v) {
        b[o]     = (byte) (v >>> 24);
        b[o + 1] = (byte) (v >>> 16);
        b[o + 2] = (byte) (v >>> 8);
        b[o + 3] = (byte) v;
    }

    private static void putLong(byte[] b, int o, long v) {
        for (int i = 0; i < 8; i++) b[o + i] = (byte) (v >>> (56 - 8 * i));
    }

    private static void closeQuietly(java.io.Closeable c) {
        if (c != null) try { c.close(); } catch (IOException ignored) { }
    }

    private static void closeQuietly(Socket s) {
        if (s != null) try { s.close(); } catch (IOException ignored) { }
    }

    private static void joinQuietly(Thread t) {
        if (t != null) try { t.join(500); } catch (InterruptedException ignored) { }
    }

    private static final class Packet {
        final int type, flags;
        final long pts;
        final byte[] payload;
        Packet(int type, int flags, long pts, byte[] payload) {
            this.type = type; this.flags = flags; this.pts = pts; this.payload = payload;
        }
    }
}
```

```java
// Read until two consecutive valid headers chain up, then you are locked.
private boolean sync(DataInputStream in, byte[] hdr) throws IOException {
    int w = 0;
    while (true) {
        int b = in.read();
        if (b < 0) return false;
        w = (w << 8) | b;
        if (w != 0x56535431) continue;                 // scan for "VST1"
        in.readFully(hdr, 4, 16);                      // rest of the header
```

## 9. Hard limits of the no-adb path

- **Input injection is impossible** from a normal app — `INJECT_EVENTS` is signature-level. ## 1. Why not a second socket

The head-of-line worry is correct but it is **a sender-side problem, not a socket-count problem**.

| design | video bytes that can precede a cursor line |
|---|---|
| today's stream + whole-AU writes | one keyframe (60–200 KB) **plus** auto-tuned kernel buffer → 60–300 ms |
| one socket, 8 KiB chunks, 64 KiB `SO_SNDBUF`, priority writer | ≤ 72 KiB → 6–24 ms |
| two sockets, video unpaced | unbounded — the video flow fills the AP queue and your control packets queue behind it in the driver/AP, where you have no control at all |

Two TCP flows over one Wi-Fi link share one bottleneck queue. A second socket removes *application* ordering but not *network* queueing, and TCP's congestion controller will happily keep the AP queue full. To make socket #2 actually low-latency you must pace and bound the video sender anyway — i.e. do all the work of the single-socket design, then also pay for:

- `pump()` (line 425) is one thread, one socket, one backoff. Two sockets means two connect/retry state machines and a "video up, control down" limbo state.
- The Mac listener accepts anyone on the LAN and keeps a single `client`, cancelling the previous (line 383). Pairing two connections to the same phone needs a nonce handshake and an orphan-connection reaper.
- Two half-open detections, two sets of status UI, a reconnect race where the two sockets disagree about which generation they belong to.

That is a real bug surface for ~15 ms. **And if latency under packet loss ever dominates, the right move is video over UDP** (drop instead of retransmit), not a second TCP socket — a second TCP socket is the worst of both: extra plumbing, still head-of-line blocked within the video stream itself.

Escape hatch is built in: the `HELLO` capability string can later advertise `vid2` and move video to its own connection **without changing one byte of the frame format**. Design for it; don't build it.

## 2. Frame header — exactly 8 bytes

All multi-byte integers are **big-endian** (free on Android's `DataOutputStream`; Swift needs `.bigEndian`).

```
 offset size field      value / meaning
 ------ ---- ---------- ------------------------------------------------------
   0     1   magic      0xAB   constant. 0xAB is a UTF-8 *continuation* byte,
                               so it can never begin a legacy ASCII command line.
   1     1   type       frame type (table below)
   2     1   flags      bitfield (table below)
   3     1   hsum       XOR of the other 7 header bytes (0,1,2,4,5,6,7)
   4     4   length     uint32 BE, payload byte count, 0 .. 1048576
   8     .   payload    exactly `length` bytes
```

`length` is 4-byte aligned inside the header, which keeps the Swift read path simple. `hsum` is what makes resync reliable (§7) — it costs one XOR per frame.

### Types

```
 0x01  TXT   one legacy command line, payload = the exact line bytes, NO trailing '\n'
 0x02  VID   H.264 access unit, or one chunk of one
 0x03  VCFG  codec config + stream geometry (must precede the first VID)
 0x04  EVT   mac -> phone input event
 0x05  CTL   flow control / feedback, either direction
 0x06..0xFF  reserved
```

**Forward-compat rule:** an unknown `type` is *not* a desync. Skip `length` bytes and continue. This is how every future feature ships without another handshake.

### Flags

```
 bit 0  0x01  KEY       this VID chunk belongs to an IDR access unit
                        (set on EVERY chunk of that AU, not just the first)
 bit 1  0x02  CONT      continuation chunk of the AU started by the previous VID frame
 bit 2  0x04  LAST      final chunk of this AU (also set on single-chunk AUs)
 bit 3  0x08  DISCONT   sender dropped >=1 AU before this one; decoder gap expected
                        (only valid together with KEY)
 bits 4-7     reserved, sender MUST zero, receiver MUST ignore
```

An access unit on the wire is: one VID with `CONT=0`, then zero or more with `CONT=1`, the last of which has `LAST=1`.

## 3. Payload layouts

### TXT (0x01) — both directions

Payload is the command line verbatim, minus the `\n`. `"M 12.5 -3.2"` becomes an 11-byte payload. The Mac hands it to `run(command:)` unchanged; the phone hands it to `handleFromMac()` unchanged. **The command vocabulary, the parsers, and the semantics do not change at all** — only the bytes around them.

### VCFG (0x03) — phone → mac

```
  0   2  u16 BE  width        pixels of the encoded video
  2   2  u16 BE  height
  4   1  u8      rotation     0,1,2,3 = 0/90/180/270 clockwise
  5   1  u8      codec        1 = H.264, NALs 4-byte-BE length-prefixed (AVCC)
  6   2  u16 BE  target_fps
  8   4  u32 BE  target_bitrate_bps
 12   2  u16 BE  csd_len
 14   .  bytes   csd: SPS then PPS, same 4-byte-BE length-prefixed form
```

**Why AVCC and not Annex B:** VideoToolbox's `CMVideoFormatDescriptionCreateFromH264ParameterSets` + `VTDecompressionSession` consume length-prefixed samples directly. MediaCodec emits Annex B; converting start codes to lengths on the phone is one pass over a buffer it already owns, and it saves the Mac a copy per frame on the latency-critical side.

VCFG must be sent: before the first VID; on any resolution/rotation/codec change; and immediately before any IDR that carries `DISCONT` or follows a resync. Configure the encoder with a 2 s IDR interval and `KEY_PREPEND_HEADER_TO_SYNC_FRAMES`, so any IDR is a valid join point.

### VID (0x02) — phone → mac

```
 chunk with CONT=0 (first chunk of an AU):
   0   4  u32 BE  frame_id     monotonic, wraps
   4   8  u64 BE  pts_us       phone monotonic clock, microseconds
  12   .  bytes   AVCC NAL bytes, first slice

 chunk with CONT=1:
   0   4  u32 BE  frame_id     same value — lets resync tell which AU it landed in
   4   .  bytes   AVCC NAL bytes, next slice
```

Chunk boundaries are **arbitrary byte offsets** — do not try to align them to NAL boundaries; a single slice NAL routinely exceeds 8 KiB. The receiver just concatenates.

### EVT (0x04) — mac → phone, 16 bytes + optional tail

```
  0   1  u8      kind   1 TOUCH_DOWN  2 TOUCH_MOVE  3 TOUCH_UP  4 TOUCH_CANCEL
                        5 SCROLL      6 KEY_DOWN    7 KEY_UP    8 TEXT
                        9 BUTTON (1=back 2=home 3=recents 4=power 5=volup 6=voldn)
  1   1  u8      pointer_id  0..9
  2   2  u16 BE  x      in VIDEO pixel space of the last VCFG (0..width-1)
  4   2  u16 BE  y      (0..height-1)
  6   2  u16 BE  pressure    0..65535, 0 for non-touch kinds
  8   2  i16 BE  scroll_h    ticks * 128, signed
 10   2  i16 BE  scroll_v
 12   4  u32 BE  code   kind-dependent: keycode | button id | (kind 8) UTF-8 tail length
 16   .  bytes   tail, only for kind 8 TEXT: UTF-8 bytes to inject
```

Coordinates are in **video space, not phone-display space**: the Mac never has to learn the real panel size, and a rotation arrives as a new VCFG that redefines the space atomically. The phone scales to its display.

(Implementation note, not protocol: the phone needs an AccessibilityService or an adb-backed shim to inject these — MediaProjection grants capture, never injection.)

### CTL (0x05) — both directions, 8 bytes + optional tail

```
  0   1  u8      op
                   1 FRAME_ACK     mac decoded+presented through frame_id
                   2 REQUEST_KEY   mac needs an IDR now
                   3 SET_BITRATE   mac asks for a bitrate ceiling
                   4 PAUSE_VIDEO   mac window hidden/occluded — stop encoding
                   5 RESUME_VIDEO
                   6 STATS         phone -> mac telemetry
  1   1  u8      reason / reserved (0)
  2   2  u16 BE  aux  (FRAME_ACK: mac decode-queue depth; REQUEST_KEY: reason code)
  4   4  u32 BE  frame_id (FRAME_ACK) | bitrate_bps (SET_BITRATE) | 0
  8   .  bytes   STATS tail: 4x u32 BE = frames_sent, frames_dropped,
                 current_bitrate_bps, queued_bytes
```

`PAUSE_VIDEO` on `NSWindow.occlusionState == []` is the single cheapest win in the whole system — zero bytes and zero encode while the window is behind Xcode.

## 4. Mode negotiation — byte-exact, no timing races

Each direction switches independently, triggered by an **in-band sentinel line**, so neither reader ever has to guess where in the byte stream the other side flipped.

```
phone                                              mac
  connect, TCP_NODELAY (already set, line 431)
  "HELLO 2 vid,evt\n"            ------------>     parses verb HELLO
                                 <------------     "HELLO 2 vid,evt\n"
                                                   "BINARY\n"      <- mac writer flips HERE
  reader sees "BINARY" -> reader flips
  "BINARY\n"                     ------------>     reader sees "BINARY" -> reader flips
  writer flips after that line
  [frames only from here]                          [frames only from here]
```

Rules:
- A reader flips to framed mode **immediately after the `\n` of a `BINARY` line it parsed**. Unambiguous byte position, no clocks involved.
- A writer flips **immediately after flushing its own `BINARY\n`**.
- Between `HELLO` and `BINARY` the phone may keep sending normal legacy lines (`M`, `C`, `S`). Nothing special happens; they are still lines.
- The flip is permanent for the life of the connection. Reconnect restarts in legacy mode.

**Compatibility matrix — verified against the current source, not assumed:**

| | new Mac | old Mac |
|---|---|---|
| **new phone** | both flip, video runs | Mac's verb switch ends in `default: break` (Surface.swift:536) so `HELLO` is silently dropped; phone's 750 ms timer expires, phone stays in legacy line mode forever, video disabled, status reads "mirroring needs the newer Mac app" |
| **old phone** | phone never sends `HELLO`, so the Mac never replies; both stay in legacy line mode | today, unchanged |

Old phones ignore unknown mac→phone lines too: `handleFromMac()` (line 464) only acts on the `APPS ` and `CLIP ` prefixes and drops everything else.

## 5. Invariants

1. **One writer thread per socket, always.** Two threads writing a shared socket interleave mid-frame and corrupt the stream. Today's `outbox` loop (line 452) is already the single writer — keep that property; video must be enqueued, never written directly from the encoder callback.
2. **Once an AU's first chunk is written, that AU must be completed.** Drops only ever discard AUs that have not started. There is no mid-AU abort.
3. **Never drop a frame and then send a P-frame.** Any drop invalidates every later reference, so a drop *forces* the next transmitted AU to be an IDR with `DISCONT` set. Getting this wrong is what produces the smeared-garbage mirror that homegrown streamers are famous for.
4. **Reading never waits on decoding.** The Mac reads on its own queue, dispatches TXT synchronously (that's the cursor), and hands VID to a bounded decode queue. Decode backlog must never delay the next `receive`.
5. **TXT frames preserve the existing line semantics exactly**, including `K `'s "everything after the verb, verbatim" rule and the `\\n` escaping both sides already do.
6. Senders zero reserved bits; receivers ignore them. Receivers skip unknown types by length.

## 6. Backpressure — three layers on the phone

**Layer 0 — the signal.** `SO_SNDBUF = 64 KiB`, blocking writes, single writer thread. When the Mac or the link falls behind, `write()` blocks. *That block is the backpressure signal* — no polling, no ACK round trip needed. The encoder output callback never touches the socket; it enqueues.

**Layer 1 — drop policy (bounded queue).** Video queue caps: **2 pending AUs or 256 KiB**, whichever hits first. On overflow:

```
discard every queued AU (none has been written yet, by invariant 2)
dropped += n
needKey = true
encoder.setParameters(PARAMETER_KEY_REQUEST_SYNC_FRAME, 0)
while needKey: ignore every non-IDR AU the encoder produces
on the IDR: send VCFG, then the AU with KEY|DISCONT set
```

The control queue is **unbounded and never dropped** — cursor and key events are tiny and losing them is a correctness bug, not a quality knob.

**Layer 2 — bitrate adaptation (AIMD, 500 ms control interval).**

```
goodput = bytes_accepted_by_socket / interval      # not bytes encoded
stalled = time_blocked_in_write / interval

if dropped_this_interval > 0 or stalled > 0.5:
    target = max(0.70 * goodput, 600_000)          # multiplicative decrease
    bad_intervals += 1
elif queue_empty_all_interval:
    good_intervals += 1
    if good_intervals >= 3:
        target = min(1.10 * target, ceiling)        # gentle increase
        good_intervals = 0

encoder.setParameters(PARAMETER_KEY_VIDEO_BITRATE, target)
```

Degrade in this order, because it is the order a human notices least:
1. bitrate down to 600 kbps floor;
2. then fps 60 → 30 → 24;
3. then halve the encode resolution (new VCFG + forced IDR).

Clamp `target` to 600 kbps … 12 Mbps and change it at most once per interval, or the loop oscillates visibly. `ceiling` is `min(12 Mbps, last SET_BITRATE from the Mac)`.

**Mac side, mirrored.** If the decode queue exceeds 3 AUs, drop to the next keyframe and send `REQUEST_KEY` — same rule 3, same reasoning. Send `FRAME_ACK` on present, which gives the phone a free end-to-end latency estimate (`now - pts_us`) for free; if that exceeds 250 ms, treat it as a stall even when nothing blocked.

## 7. Resync after a partial read

Two different things get conflated here; keep them apart.

**Partial reads are normal and are not desync.** TCP hands you arbitrary boundaries. The reader is a two-state machine, `AT_HEADER` / `IN_PAYLOAD(n)`, over a persistent byte buffer. It never assumes a read returns a whole header or a whole payload. Today's Mac reader is where this will bite: it does `String(data:encoding:.utf8)` per chunk (Surface.swift:380) and accumulates a `String` — which already silently drops any chunk ending mid-UTF-8-sequence, and will destroy binary outright. It must become a `Data` buffer.

**True desync** (version skew, a mode-flip bug, a mangled write) is detected by: `magic != 0xAB`, or `hsum` mismatch, or `length > MAX_PAYLOAD`. Unknown `type` is explicitly *not* desync.

```
RESYNC(buf):
  scan i from 0 over buf:
    if buf[i] != 0xAB: continue
    if not enough bytes for a header at i: need more data, keep i
    if hsum(buf[i..i+8]) invalid: continue
    len = u32BE(buf[i+4])
    if len > MAX_PAYLOAD: continue
    if type(buf[i+1]) not in KNOWN_TYPES: continue      # stricter than steady state,
                                                        # only while resyncing
    if buffered beyond i+8+len and buf[i+8+len] != 0xAB: continue
    # require TWO consecutive plausible headers before trusting sync
    accept at i
  bytes_scanned += ...
  if bytes_scanned > 1 MiB or elapsed > 2 s: close the socket
```

On accepting sync: discard any partially assembled AU, set `needKey`, send `CTL REQUEST_KEY`.

**And be honest about the real safety net:** `pump()` already reconnects in ~1 s with discovery intact. Resync is the optimization that avoids a visible blink; **closing the connection is the guarantee**. Never loop forever trying to resync — bound it and drop.

In legacy line mode the recovery is unchanged from today: discard to the next `\n`.

### Mac reader — `Data` buffer, resync, decode off the read path

```swift
private var buf = Data()                  // was a String — that was the bug
private var framedIn = false
private var pending: (hdr: Hdr, body: Data)? = nil

private func read(_ conn: NWConnection) {
  conn.receive(minimumIncompleteLength: 1, maximumLength: 65536) { data, _, done, _ in
    if let d = data { self.buf.append(d) }
    self.drain()
    if done { conn.cancel() } else { self.read(conn) }
  }
}

private func drain() {
  while true {
    if !framedIn {
      guard let nl = buf.firstIndex(of: 0x0A) else { return }
      let line = String(decoding: buf[..<nl], as: UTF8.self)
      buf.removeSubrange(...nl)
      if line == "BINARY" { framedIn = true; continue }
      if line.hasPrefix("HELLO ") { replyHello(); continue }   // then send "BINARY\n", flip writer
      run(command: line)                                      // UNCHANGED
      continue
    }

    guard buf.count >= 8 else { return }
    guard buf[0] == 0xAB, hsumOK(buf), let len = sane(u32be(buf, 4)) else {
      guard resync() else { conn.cancel(); return }            // §7
      continue
    }
    guard buf.count >= 8 + len else { return }                 // partial payload: wait
    let type = buf[1], flags = buf[2]
    let body = buf.subdata(in: 8 ..< 8+len)
    buf.removeSubrange(0 ..< 8+len)

    switch type {
    case TXT:  DispatchQueue.main.async { self.run(command: String(decoding: body, as: UTF8.self)) }
    case VCFG: decodeQueue.async { self.applyConfig(body) }
    case VID:  assemble(flags, body)        // appends; on LAST -> decodeQueue.async { decode }
    case CTL:  onCtl(body)
    default:   break                        // unknown type: already skipped by length
    }
  }
}
```

`assemble` enforces the AU rules: `CONT=0` starts a new AU (any unfinished one is discarded and `REQUEST_KEY` is sent); `CONT=1` with no AU in progress is discarded and triggers `REQUEST_KEY`; `LAST` closes it and dispatches to the decoder. If the decode queue already holds 3 AUs, drop to the next `KEY` and send `REQUEST_KEY`.

## 9. Concrete migration points in the existing code

These four are where a naive binary bolt-on silently regresses:

1. **`Surface.swift:397-408`** — the reader accumulates a `String` and decodes UTF-8 per chunk. Binary cannot survive this, and it *already* drops any chunk that ends mid-multibyte-sequence. Replace with the `Data` buffer above; the UTF-8 bug goes away as a side effect.
2. **`MainActivity.java:432`** — `BufferedWriter(new OutputStreamWriter(...))` is a character stream. Replace with `BufferedOutputStream`, encode text explicitly as ASCII.
3. **`MainActivity.java:442`** — `BufferedReader.readLine()` will eat `\n` bytes that occur inside video payloads. Replace with a byte-level `DataInputStream` reader.
4. **`MainActivity.java:452`** — `outbox.take()` is the single writer and must stay the single writer. Split into `ctrlQ` + `vidQ` with the priority loop; never write from the MediaCodec callback thread.

Unchanged by design: `run(command:)`'s verb switch, `handleFromMac()`, `send(String)`, UDP discovery on 8789, the `WHO`/`MAC` exchange, the 3 s `PING` heartbeat (line 131), `TCP_NODELAY` (already set on both ends), and the "cancel the previous client" reconnect rule.

```swift
/// One NAL unit inside a received payload: offset of the NAL *header* byte
/// (start code / length prefix already skipped) and its length.
struct NALUnit {
    let offset: Int
    let length: Int
    /// nal_unit_type — low 5 bits of the NAL header byte.
    /// 1 = non-IDR slice, 5 = IDR slice, 6 = SEI, 7 = SPS, 8 = PPS, 9 = AUD.
    let type: UInt8

    var isVCL: Bool { type >= 1 && type <= 5 }
    var isIDR: Bool { type == 5 }
    var isParameterSet: Bool { type == 7 || type == 8 }
}

enum H264Parser {

    /// Next Annex-B start code at or after `from`: (offset of first 0x00, size 3 or 4).
    @inline(__always)
    static func findStartCode(_ p: UnsafePointer<UInt8>, _ count: Int, from: Int) -> (offset: Int, size: Int)? {
        var i = max(0, from)
        while i + 2 < count {
            if p[i] == 0 && p[i + 1] == 0 {
                if p[i + 2] == 1 { return (i, 3) }
                if p[i + 2] == 0 && i + 3 < count && p[i + 3] == 1 { return (i, 4) }
                // A run of 00 00 00 00 … may still end in 01, so slide one byte.
            }
            i += 1
        }
        return nil
    }

    @inline(__always)
    static func startsWithStartCode(_ p: UnsafePointer<UInt8>, _ count: Int) -> Bool {
        if count >= 4 && p[0] == 0 && p[1] == 0 && p[2] == 0 && p[3] == 1 { return true }
        if count >= 3 && p[0] == 0 && p[1] == 0 && p[2] == 1 { return true }
        return false
    }

    /// True only when a chain of 4-byte big-endian length-prefixed NALs walks
    /// exactly to the end of the payload, which makes a false positive
    /// essentially impossible.
    static func isAVCC(_ p: UnsafePointer<UInt8>, _ count: Int) -> Bool {
        var i = 0
        while i + 4 <= count {
            let n = Int(UInt32(p[i]) << 24 | UInt32(p[i + 1]) << 16 | UInt32(p[i + 2]) << 8 | UInt32(p[i + 3]))
            if n <= 0 { return false }
            i += 4 + n
            if i > count { return false }
        }
        return i == count
    }

    /// Splits a payload into NAL units under whichever of the three framings
    /// the sender used. Start codes and length prefixes are excluded.
    static func split(_ p: UnsafePointer<UInt8>, _ count: Int) -> [NALUnit] {
        guard count > 0 else { return [] }
        var out: [NALUnit] = []
        out.reserveCapacity(4)

        if startsWithStartCode(p, count) {
            guard var sc = findStartCode(p, count, from: 0) else { return [] }
            while true {
                let bodyStart = sc.offset + sc.size
                let next = findStartCode(p, count, from: bodyStart)
                var bodyEnd = next?.offset ?? count
                // Trailing zeros belong to the next start code, or are
                // cabac_zero_words padding. 0x00 is never the last RBSP byte,
                // so trimming them is always safe.
                while bodyEnd > bodyStart && p[bodyEnd - 1] == 0 { bodyEnd -= 1 }
                if bodyEnd > bodyStart {
                    out.append(NALUnit(offset: bodyStart,
                                       length: bodyEnd - bodyStart,
                                       type: p[bodyStart] & 0x1F))
                }
                guard let n = next else { break }
                sc = n
            }
            return out
        }

        if isAVCC(p, count) {
            var i = 0
            while i + 4 <= count {
                let n = Int(UInt32(p[i]) << 24 | UInt32(p[i + 1]) << 16 | UInt32(p[i + 2]) << 8 | UInt32(p[i + 3]))
                out.append(NALUnit(offset: i + 4, length: n, type: p[i + 4] & 0x1F))
                i += 4 + n
            }
            return out
        }

        return [NALUnit(offset: 0, length: count, type: p[0] & 0x1F)]
    }
}

/// One sample buffer per **access unit**, not per NAL.
///
/// This is the detail that silently ruins naive ports: a single picture can be
/// carried in several slice NALs, and VideoToolbox will not decode a picture
/// whose slices arrive in separate sample buffers. Every VCL NAL of one
/// picture, plus its SEI, goes into one CMBlockBuffer as `[u32 len][NAL]…`.
///
/// SPS/PPS/AUD are dropped from the sample data: parameter sets live in the
/// format description, and an in-band copy makes some VideoToolbox builds
/// return kVTVideoDecoderBadDataErr.
func makeSampleBuffer(payload: UnsafePointer<UInt8>,
                      nals: [NALUnit],
                      format: CMVideoFormatDescription,
                      pts: CMTime,
                      duration: CMTime = .invalid,
                      displayImmediately: Bool) throws -> CMSampleBuffer? {

    let kept = nals.filter { !$0.isParameterSet && $0.type != 9 && $0.length > 0 }
    guard !kept.isEmpty else { return nil }

    let total = kept.reduce(0) { $0 + 4 + $1.length }

    // malloc'd and handed to CoreMedia with kCFAllocatorMalloc as the *block
    // allocator*: the CMBlockBuffer then owns it and frees it when its last
    // reference dies. No copy on enqueue, nothing to free by hand. Passing nil
    // there instead would mean "not mine", and this buffer would leak.
    guard let raw = malloc(total) else { return nil }
    let dst = raw.assumingMemoryBound(to: UInt8.self)
    var w = 0
    for n in kept {
        let len = UInt32(n.length)
        dst[w + 0] = UInt8(truncatingIfNeeded: len >> 24)
        dst[w + 1] = UInt8(truncatingIfNeeded: len >> 16)
        dst[w + 2] = UInt8(truncatingIfNeeded: len >> 8)
        dst[w + 3] = UInt8(truncatingIfNeeded: len)
        memcpy(dst + w + 4, payload + n.offset, n.length)
        w += 4 + n.length
    }

    var block: CMBlockBuffer?
    let bbStatus = CMBlockBufferCreateWithMemoryBlock(
        allocator: kCFAllocatorDefault,
        memoryBlock: raw,
        blockLength: total,
        blockAllocator: kCFAllocatorMalloc,
        customBlockSource: nil,
        offsetToData: 0,
        dataLength: total,
        flags: 0,
        blockBufferOut: &block)
    guard bbStatus == kCMBlockBufferNoErr, let block else {
        free(raw)
        throw ReceiverError.blockBuffer(bbStatus)
    }

    var timing = CMSampleTimingInfo(duration: duration,
                                    presentationTimeStamp: pts,
                                    decodeTimeStamp: .invalid)
    var size = total
    var sample: CMSampleBuffer?
    let sbStatus = CMSampleBufferCreateReady(
        allocator: kCFAllocatorDefault,
        dataBuffer: block,
        formatDescription: format,
        sampleCount: 1,
        sampleTimingEntryCount: 1,
        sampleTimingArray: &timing,
        sampleSizeEntryCount: 1,
        sampleSizeArray: &size,
        sampleBufferOut: &sample)
    guard sbStatus == noErr, let sample else { throw ReceiverError.sampleBuffer(sbStatus) }

    annotate(sample,
             displayImmediately: displayImmediately,
             isSync: kept.contains { $0.isIDR })
    return sample
}

/// `kCMSampleAttachmentKey_DisplayImmediately` and
/// `kCMSampleAttachmentKey_NotSync` are *per-sample* attachments: they go in
/// the sample-attachments array, not in the buffer-level attachments that
/// `CMSetAttachment` writes. Putting them in the wrong place is a silent no-op
/// — the frame simply never appears, with no error anywhere.
@inline(__always)
func annotate(_ sample: CMSampleBuffer, displayImmediately: Bool, isSync: Bool) {
    guard let atts = CMSampleBufferGetSampleAttachmentsArray(sample, createIfNecessary: true),
          CFArrayGetCount(atts) > 0 else { return }
    let dict = unsafeBitCast(CFArrayGetValueAtIndex(atts, 0), to: CFMutableDictionary.self)
    if displayImmediately {
        CFDictionarySetValue(dict,
                             Unmanaged.passUnretained(kCMSampleAttachmentKey_DisplayImmediately).toOpaque(),
                             Unmanaged.passUnretained(kCFBooleanTrue).toOpaque())
    }
    // Absent NotSync means "this is a sync sample". Marking P-frames lets the
    // renderer pick a correct resync point after a flush.
    if !isSync {
        CFDictionarySetValue(dict,
                             Unmanaged.passUnretained(kCMSampleAttachmentKey_NotSync).toOpaque(),
                             Unmanaged.passUnretained(kCFBooleanTrue).toOpaque())
    }
}

/// How frames are scheduled. These two are mutually exclusive by Apple's own
/// guidance — see the long comment in `init`.
enum Pacing {
    /// No control timebase, no render synchronizer, `DisplayImmediately` on
    /// every sample. Lowest latency; frame intervals are whatever the network
    /// delivers. This is what you want for mirroring.
    case immediate
    /// A clock running at rate 1.0 and real presentation timestamps, with no
    /// `DisplayImmediately`. Costs one `targetLatency` of delay and buys even
    /// pacing. Use it if the immediate path looks judder-y on your link.
    case clocked

/// Owns every interaction with the AVSampleBufferDisplayLayer after creation.
/// All of it runs on one serial queue, off the main thread, so a busy main
/// thread never stalls video — and on macOS 14+ that is explicitly sanctioned,
/// since `sampleBufferRenderer` exists to make background enqueueing safe
/// (AVSampleBufferDisplayLayer.h, `sampleBufferRenderer` discussion).
final class VideoRenderer {

    private let layer: AVSampleBufferDisplayLayer
    private let pacing: Pacing
    private let queue = DispatchQueue(label: "mirror.render", qos: .userInteractive)

    /// class still compiles and runs with an older deployment target.

    private var synchronizer: AVSampleBufferRenderSynchronizer?   // macOS 10.13+
    private let useRenderer: Bool
    private var clockStarted = false

    /// How far ahead of "now" clocked samples are stamped. Below roughly one
    /// frame interval the renderer starts discarding samples as late.
    private let targetLatency = CMTime(value: 40, timescale: 1000)

    private var format: CMVideoFormatDescription?
    private var sps: [UInt8]?
    private var pps: [UInt8]?
    /// Host time of the first frame. PTS is measured from it, so the stream
    /// starts at zero and lines up with a clock also started at zero.
    private var epoch: CMTime?

    /// Set after any flush. While true every non-IDR access unit is discarded.
    private var awaitingIDR = true

    /// Invoked when the sender needs to produce an IDR immediately.
    var requestKeyFrame: (() -> Void)?

    /// Encoded picture size, for hit testing. Main-thread only.
    private(set) var videoSize: CGSize = .zero

    init(layer: AVSampleBufferDisplayLayer, pacing: Pacing = .immediate) {
        self.layer = layer
        self.pacing = pacing

        // --- the timebase decision -------------------------------------
        //
        // AVSampleBufferDisplayLayer.h documents that pairing either a
        // non-NULL controlTimebase or an AVSampleBufferRenderSynchronizer
        // with DisplayImmediately is not recommended (header line ~137).
        // They are two answers to the same question — "when is this frame
        // due?" — and the layer honours whichever it sees last, so running
        // both produces timing that is neither.
        //
        // So: .immediate leaves controlTimebase nil and attaches no
        // synchronizer. .clocked installs exactly one clock and drops the
        // DisplayImmediately attachment.
        //
        // The failure this prevents in the other direction matters just as
        // much: with controlTimebase nil AND no DisplayImmediately, the
        // layer's time never advances, so no sample is ever due and the
        // window stays black forever — with status == .rendering and no
        // error reported anywhere. That is the single most common way this
        // pipeline "silently doesn't work".
        if pacing == .clocked, #available(macOS 14.0, *) {
            // Non-deprecated path, and the only clock that works with
            // sampleBufferRenderer (the renderer's own timebase is read-only).
            let r = layer.sampleBufferRenderer
            let sync = AVSampleBufferRenderSynchronizer()
            sync.addRenderer(r)
            videoRenderer = r
            synchronizer = sync
            useRenderer = true
        } else {
            useRenderer = false
            if pacing == .clocked { installControlTimebase() }
        }
    }

    /// Pre-macOS-14 clocked path.
    ///
    /// `CMTimebaseCreateWithSourceClock` is macOS 10.8+ — it is only a rename
    /// of `CMTimebaseCreateWithMasterClock`, which was deprecated back in
    /// macOS 10.10, so there is no reason to ever call the old spelling.
    /// `AVSampleBufferDisplayLayer.controlTimebase` is macOS 10.8+ and,
    /// unlike the rest of that class's rendering surface, is NOT deprecated.
    private func installControlTimebase() {
        var tb: CMTimebase?
        guard CMTimebaseCreateWithSourceClock(allocator: kCFAllocatorDefault,
                                              sourceClock: CMClockGetHostTimeClock(),
                                              timebaseOut: &tb) == noErr,
              let tb else { return }
        // A fresh timebase is rate 0, time 0. Leaving the rate at 0 is the
        // other classic black-window bug.
        CMTimebaseSetTime(tb, time: .zero)
        CMTimebaseSetRate(tb, rate: 1.0)
        layer.controlTimebase = tb
    }

    private func startClockIfNeeded() {
        guard pacing == .clocked, !clockStarted else { return }
        clockStarted = true
        synchronizer?.setRate(1.0, time: .zero)   // macOS 10.13+
    }

    // ---- renderer shims ---------------------------------------------------
    // macOS 15.0 deprecated every AVQueuedSampleBufferRendering member on the
    // layer in favour of layer.sampleBufferRenderer. One place absorbs that
    // split so the frame path below reads the same on every OS.

    private var isReadyForMore: Bool {
        if useRenderer, #available(macOS 14.0, *),
           let r = videoRenderer as? AVSampleBufferVideoRenderer { return r.isReadyForMoreMediaData }
        return layer.isReadyForMoreMediaData
    }

    private var rendererStatus: AVQueuedSampleBufferRenderingStatus {
        if useRenderer, #available(macOS 14.0, *),
           let r = videoRenderer as? AVSampleBufferVideoRenderer { return r.status }
        return layer.status
    }

    private var rendererError: Error? {
        if useRenderer, #available(macOS 14.0, *),
           let r = videoRenderer as? AVSampleBufferVideoRenderer { return r.error }
        return layer.error
    }

    private var needsFlushToResume: Bool {
        if useRenderer, #available(macOS 14.0, *),
           let r = videoRenderer as? AVSampleBufferVideoRenderer { return r.requiresFlushToResumeDecoding }
        if #available(macOS 11.0, *) { return layer.requiresFlushToResumeDecoding }
        return false
    }

    private func enqueue(_ sample: CMSampleBuffer) {
        if useRenderer, #available(macOS 14.0, *),
           let r = videoRenderer as? AVSampleBufferVideoRenderer { r.enqueue(sample); return }
        layer.enqueue(sample)
    }

    /// A plain flush drops queued samples and leaves the last displayed frame
    /// on screen — what you want mid-stream, because a black blink on every
    /// recovered glitch reads worse than one stale frame. Removing the image
    /// is for disconnect.
    private func flush(removingImage: Bool = false) {
        if useRenderer, #available(macOS 14.0, *),
           let r = videoRenderer as? AVSampleBufferVideoRenderer {
            if removingImage { r.flush(removingDisplayedImage: true, completionHandler: nil) } else { r.flush() }
            return
        }
        if removingImage { layer.flushAndRemoveImage() } else { layer.flush() }
    }

    // ---- feeding ----------------------------------------------------------

    /// Hand one received payload to the renderer. Safe from the network thread.
    func submit(payload: [UInt8]) {
        queue.async { [weak self] in self?.handle(payload) }
    }

    private func handle(_ payload: [UInt8]) {
        payload.withUnsafeBufferPointer { buf in
            guard let base = buf.baseAddress else { return }
            let nals = H264Parser.split(base, buf.count)
            guard !nals.isEmpty else { return }

            // Parameter sets arrive either alone (MediaCodec's csd-0 holds SPS
            // and PPS together, start-code separated) or inline before every
            // IDR. Rebuild the format description only when the bytes actually
            // change — rebuilding on every IDR restarts the decode session and
            // shows up as a periodic hitch.
            var changed = false
            for n in nals where n.isParameterSet {
                let bytes = Array(UnsafeBufferPointer(start: base + n.offset, count: n.length))
                if n.type == 7, bytes != sps { sps = bytes; changed = true }
                if n.type == 8, bytes != pps { pps = bytes; changed = true }
            }
            if changed, let sps, let pps {
                do {
                    let fmt = try makeH264FormatDescription(sps: sps, pps: pps)
                    format = fmt
                    let d = CMVideoFormatDescriptionGetDimensions(fmt)
                    let size = CGSize(width: CGFloat(d.width), height: CGFloat(d.height))
                    DispatchQueue.main.async { [weak self] in self?.videoSize = size }
                    awaitingIDR = true          // rotation / resolution change
                    flush()
                } catch {
                    FileHandle.standardError.write(Data("format description: \(error)\n".utf8))
                    return
                }
            }

            guard let format else { return }                        // no SPS/PPS yet
            guard nals.contains(where: { $0.isVCL }) else { return } // SEI/AUD-only AU

            if awaitingIDR {
                guard nals.contains(where: { $0.isIDR }) else { requestKeyFrame?(); return }
                awaitingIDR = false
            }

            recoverIfNeeded()
            if awaitingIDR { return }   // recoverIfNeeded just flushed

            // Back-pressure. Buffering would trade the one thing we are here
            // for, so drop to the next IDR instead and ask for one.
            if !isReadyForMore {
                awaitingIDR = true
                flush()
                requestKeyFrame?()
                return
            }

            let now = CMClockGetTime(CMClockGetHostTimeClock())
            if epoch == nil { epoch = now }
            var pts = CMTimeSubtract(now, epoch!)
            if pacing == .clocked { pts = CMTimeAdd(pts, targetLatency) }
            pts = CMTimeConvertScale(pts, timescale: 90_000, method: .roundHalfAwayFromZero)

            do {
                if let sample = try makeSampleBuffer(payload: base,
                                                     nals: nals,
                                                     format: format,
                                                     pts: pts,
                                                     displayImmediately: pacing == .immediate) {
                    startClockIfNeeded()
                    enqueue(sample)
                }
            } catch {
                FileHandle.standardError.write(Data("sample buffer: \(error)\n".utf8))
            }
        }
    }

    // ---- error recovery ---------------------------------------------------
    //
    // Two independent signals, polled rather than observed by notification:
    // we are already on the render queue once per frame, so polling is cheaper
    // and avoids a main-thread hop for something that must be handled before
    // the next enqueue.
    //
    //   status == .failed                 the decode session died
    //   requiresFlushToResumeDecoding     app was occluded or the GPU context
    //                                     was torn down; nothing decodes until
    //                                     a flush, and no error is reported
    //
    // Recovery is always the same shape: flush, refuse everything until an
    // IDR, nudge the sender. Skipping the second half is the usual mistake —
    // a freshly flushed decoder fed P-frames produces a smear of green blocks
    // and very often fails again straight away, which loops.
    private func recoverIfNeeded() {
        var broken = false
        if rendererStatus == .failed {
            let e = rendererError.map { String(describing: $0) } ?? "unknown"
            FileHandle.standardError.write(Data("renderer failed: \(e) — flushing\n".utf8))
            broken = true
        }
        if needsFlushToResume { broken = true }
        guard broken else { return }
        awaitingIDR = true
        flush()
        requestKeyFrame?()
    }

    func reset() {
        queue.async { [weak self] in
            guard let self else { return }
            self.format = nil
            self.sps = nil
            self.pps = nil
            self.epoch = nil
            self.clockStarted = false
            self.awaitingIDR = true
            self.synchronizer?.setRate(0, time: .zero)
            self.flush(removingImage: true)
        }
    }
}

final class MirrorView: NSView {

    let displayLayer = AVSampleBufferDisplayLayer()
    private(set) var renderer: VideoRenderer!

    /// Size of the phone's touch coordinate space. Usually identical to the
    /// encoded picture size — but a sender that downscales before encoding
    /// (a 1080x2400 panel encoded at 800x1778, say) must set this to the panel
    /// size, or every tap lands short.
    var phoneTouchSize: CGSize?

    var onTouch: ((_ action: UInt8, _ point: CGPoint) -> Void)?

    override init(frame: NSRect) {
        super.init(frame: frame)
        wantsLayer = true
        displayLayer.videoGravity = .resizeAspect
        displayLayer.backgroundColor = NSColor.black.cgColor
        renderer = VideoRenderer(layer: displayLayer, pacing: .immediate)
    }

    required init?(coder: NSCoder) { fatalError("not used") }

    // Making the display layer the *backing* layer rather than a sublayer
    // means AppKit resizes it for us and there is no extra compositing pass.
    override func makeBackingLayer() -> CALayer { displayLayer }
    override var isOpaque: Bool { true }
    override var acceptsFirstResponder: Bool { true }

    override func viewDidChangeBackingProperties() {
        super.viewDidChangeBackingProperties()
        displayLayer.contentsScale = window?.backingScaleFactor ?? 2.0
    }

    // ---- 6. window point -> phone pixel ----------------------------------
    //
    // .resizeAspect letterboxes: scale by the smaller of the two axis ratios,
    // centre, leave bars on the slack axis. Invert that exactly, and reject
    // the bars rather than clamping — a click in a black bar is not a tap.
    //
    // Three things that go wrong here:
    //
    //  1. backingScaleFactor. `bounds` is in points and so is a converted
    //     mouse location, so Retina cancels out and must NOT be applied. The
    //     only pixel space in this function is the phone's.
    //  2. Y origin. AppKit view coordinates are bottom-left (this view is
    //     unflipped); Android MotionEvent and `input tap` are top-left. Hence
    //     the single inversion at the end. Returning `isFlipped = true`
    //     instead also flips the backing layer's geometry, so prefer this.
    //  3. Rounding. `.down` keeps the result inside [0, size-1]; rounding to
    //     nearest can produce `vw`, which is off the phone's screen.
    func phonePoint(fromViewPoint p: CGPoint) -> CGPoint? {
        let target = phoneTouchSize ?? renderer.videoSize
        let vw = target.width, vh = target.height
        let b = bounds
        guard vw > 0, vh > 0, b.width > 0, b.height > 0 else { return nil }

        let scale = min(b.width / vw, b.height / vh)
        let shownW = vw * scale, shownH = vh * scale
        let originX = (b.width - shownW) / 2
        let originY = (b.height - shownH) / 2

        let x = (p.x - originX) / scale
        let yFromBottom = (p.y - originY) / scale
        guard x >= 0, x < vw, yFromBottom >= 0, yFromBottom < vh else { return nil }

        return CGPoint(x: x.rounded(.down), y: (vh - yFromBottom).rounded(.down))
    }

    private func dispatch(_ action: UInt8, _ event: NSEvent) {
        let local = convert(event.locationInWindow, from: nil)
        guard let phone = phonePoint(fromViewPoint: local) else { return }
        onTouch?(action, phone)
    }

    override func mouseDown(with event: NSEvent)    { dispatch(0, event) }  // ACTION_DOWN
    override func mouseUp(with event: NSEvent)      { dispatch(1, event) }  // ACTION_UP
    override func mouseDragged(with event: NSEvent) { dispatch(2, event) }  // ACTION_MOVE
}

final class MirrorServer {

    private let port: UInt16
    private let loopbackOnly: Bool
    private var listenFD: Int32 = -1
    private var clientFD: Int32 = -1
    private let accepts = DispatchQueue(label: "mirror.accept")
    private let writes  = DispatchQueue(label: "mirror.write")

    var onPayload: (([UInt8]) -> Void)?
    var onConnect: (() -> Void)?
    var onDisconnect: (() -> Void)?

    /// `loopbackOnly` keeps the listener on 127.0.0.1, which is all that
    /// `adb reverse tcp:27183 tcp:27183` needs, and avoids exposing an
    /// unauthenticated H.264 decoder to the local network.
    init(port: UInt16, loopbackOnly: Bool = true) {
        self.port = port
        self.loopbackOnly = loopbackOnly
    }

    func start() throws {
        signal(SIGPIPE, SIG_IGN)   // a phone that drops the link must not kill us

        let fd = socket(AF_INET, SOCK_STREAM, 0)
        guard fd >= 0 else { throw ReceiverError.socket("socket", errno) }

        var yes: Int32 = 1
        setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &yes, socklen_t(MemoryLayout<Int32>.size))

        var addr = sockaddr_in()
        addr.sin_len = UInt8(MemoryLayout<sockaddr_in>.size)
        addr.sin_family = sa_family_t(AF_INET)
        addr.sin_port = port.bigEndian
        addr.sin_addr.s_addr = loopbackOnly ? inet_addr("127.0.0.1") : INADDR_ANY.bigEndian

        let bound = withUnsafePointer(to: &addr) { ap in
            ap.withMemoryRebound(to: sockaddr.self, capacity: 1) { sa in
                Darwin.bind(fd, sa, socklen_t(MemoryLayout<sockaddr_in>.size))
            }
        }
        guard bound == 0 else { let e = errno; close(fd); throw ReceiverError.socket("bind", e) }
        guard Darwin.listen(fd, 1) == 0 else { let e = errno; close(fd); throw ReceiverError.socket("listen", e) }

        listenFD = fd
        accepts.async { [weak self] in self?.acceptLoop() }
    }

    private func acceptLoop() {
        while listenFD >= 0 {
            let fd = Darwin.accept(listenFD, nil, nil)
            if fd < 0 { if errno == EINTR { continue }; return }

            var yes: Int32 = 1
            // Without TCP_NODELAY, Nagle holds a small frame until the previous
            // segment is acked: tens of milliseconds of latency, in bursts,
            // landing exactly on the frames you notice.
            setsockopt(fd, IPPROTO_TCP, TCP_NODELAY, &yes, socklen_t(MemoryLayout<Int32>.size))

            clientFD = fd
            DispatchQueue.main.async { [weak self] in self?.onConnect?() }
            readLoop(fd)
            clientFD = -1
            close(fd)
            DispatchQueue.main.async { [weak self] in self?.onDisconnect?() }
        }
    }

    private func readLoop(_ fd: Int32) {
        var header = [UInt8](repeating: 0, count: 4)
        while true {
            guard readFully(fd, &header, 4) else { return }
            let len = Int(UInt32(header[0]) << 24 | UInt32(header[1]) << 16
                        | UInt32(header[2]) << 8  | UInt32(header[3]))
            guard len > 0, len <= 16 << 20 else {
                FileHandle.standardError.write(Data("\(ReceiverError.badFrameLength(len))\n".utf8))
                return   // resyncing a corrupt length-framed stream is not possible
            }
            var payload = [UInt8](repeating: 0, count: len)
            guard readFully(fd, &payload, len) else { return }
            onPayload?(payload)
        }
    }

    /// TCP is a byte stream, so one read() routinely returns a partial frame —
    /// always, for a 60 KB IDR. Loop until the frame is whole.
    private func readFully(_ fd: Int32, _ buf: inout [UInt8], _ count: Int) -> Bool {
        var got = 0
        return buf.withUnsafeMutableBytes { raw -> Bool in
            guard let base = raw.baseAddress else { return false }
            while got < count {
                let n = Darwin.read(fd, base + got, count - got)
                if n > 0 { got += n; continue }
                if n == 0 { return false }                        // clean EOF
                if errno == EINTR || errno == EAGAIN { continue }
                return false
            }
            return true
        }
    }

    /// Length-framed control message back to the phone.
    func send(_ bytes: [UInt8]) {
        writes.async { [weak self] in
            guard let self, self.clientFD >= 0 else { return }
            var out = [UInt8]()
            out.reserveCapacity(4 + bytes.count)
            let n = UInt32(bytes.count)
            out.append(UInt8(truncatingIfNeeded: n >> 24))
            out.append(UInt8(truncatingIfNeeded: n >> 16))
            out.append(UInt8(truncatingIfNeeded: n >> 8))
            out.append(UInt8(truncatingIfNeeded: n))
            out.append(contentsOf: bytes)
            out.withUnsafeBytes { raw in
                guard let base = raw.baseAddress else { return }
                var sent = 0
                while sent < raw.count {
                    let w = Darwin.write(self.clientFD, base + sent, raw.count - sent)
                    if w > 0 { sent += w; continue }
                    if w < 0 && (errno == EINTR || errno == EAGAIN) { continue }
                    return
                }
            }
        }
    }

    func stop() {
        if clientFD >= 0 { close(clientFD); clientFD = -1 }
        if listenFD >= 0 { close(listenFD); listenFD = -1 }
    }
}
```

## Four things that decide whether this works

**The timebase is a trap in both directions.** `AVSampleBufferDisplayLayer.h` (around line 137) says not to combine a non-nil `controlTimebase` or an `AVSampleBufferRenderSynchronizer` with `DisplayImmediately` — they answer the same question and you get neither answer. But the inverse kills you too: no clock *and* no `DisplayImmediately` means the layer's time never advances, no sample is ever due, and the window stays black with `status == .rendering` and no error anywhere. That is why `Pacing` is one enum with exactly two legal configurations instead of a pile of independent switches. For mirroring, use `.immediate`.

**One sample buffer per access unit, not per NAL.** A picture split into multiple slice NALs will not decode if the slices land in separate sample buffers. The brief asked for per-NAL; that is the one thing I changed on purpose. Strip SPS/PPS/AUD out of the sample data while you are there — the parameter sets belong to the format description, and an in-band copy gets you `kVTVideoDecoderBadDataErr` on some builds.

**The attachment goes in the per-sample dictionary.** `kCMSampleAttachmentKey_DisplayImmediately` and `kCMSampleAttachmentKey_NotSync` live in `CMSampleBufferGetSampleAttachmentsArray(_, createIfNecessary: true)[0]`, not in the buffer-level attachments `CMSetAttachment` writes. Put them in the wrong dictionary and nothing errors — the frames just never show.

**Recovery has two halves and the second one is the one people skip.** Flushing is easy; the part that matters is refusing every non-IDR access unit afterwards and asking the sender for a key frame. Feed a flushed decoder P-frames and you get green-block smear plus, very often, an immediate second failure, which loops forever. `requiresFlushToResumeDecoding` is the signal with no error attached — occlusion or a GPU context teardown — so poll it alongside `status`, which this code does once per frame on the render queue rather than via notification.

One thing I did not verify by execution: whether `sampleBufferRenderer` displays frames with `DisplayImmediately` and *no* synchronizer attached. Apple documents neither that pairing nor its absence, and all their sample code attaches a synchronizer. That is why `.immediate` deliberately stays on the layer's own (deprecated but proven) `enqueue`, and only `.clocked` moves to the renderer. If you want the non-deprecated enqueue at immediate latency, that combination is worth a 20-line spike on your target OS before you commit to it.

`canPerformGestures` is what makes `dispatchGesture()` return true instead of false; `canRetrieveWindowContent` is what makes `findFocus()`/`getRootInActiveWindow()` non-null.
```java
package com.gaurav.touchremote;

import android.accessibilityservice.AccessibilityService;
import android.accessibilityservice.AccessibilityServiceInfo;
import android.accessibilityservice.GestureDescription;
import android.accessibilityservice.GestureDescription.StrokeDescription;
import android.accessibilityservice.InputMethod;
import android.content.Intent;
import android.content.res.Configuration;
import android.graphics.Path;
import android.graphics.Point;
import android.graphics.Rect;
import android.hardware.display.DisplayManager;
import android.os.Build;
import android.os.Bundle;
import android.os.Handler;
import android.os.Looper;
import android.os.SystemClock;
import android.util.Log;
import android.view.Display;
import android.view.KeyEvent;
import android.view.ViewConfiguration;
import android.view.WindowManager;
import android.view.accessibility.AccessibilityEvent;
import android.view.accessibility.AccessibilityNodeInfo;

import java.util.ArrayDeque;

/**
 * Touch injection without adb, root or developer options.
 *
 * Everything the phone does to itself goes through here: dispatchGesture() for
 * pointer input, ACTION_SET_TEXT / the accessibility IME for text, and
 * performGlobalAction() for Back / Home / Recents.
 *
 * Two hard facts shape the whole class:
 *
 *  1. dispatchGesture() CANCELS whatever gesture is in flight — the user's
 *     finger, this service's own, or another service's. So gestures must be
 *     strictly serialised: dispatch one, wait for the callback, dispatch the
 *     next. That is what {@link #queue} is for.
 *  2. A stroke built with willContinue = true keeps its pointer DOWN after the
 *     gesture completes. The continuation has to be created from that exact
 *     StrokeDescription via continueStroke(), and dispatched only after the
 *     previous segment's onCompleted() has fired.
 */
public class TouchService extends AccessibilityService {

    static final String TAG = "TouchRemote";

    /** 60000 ms and 10, read from the framework rather than guessed. */
    static final long MAX_STROKE_MS = GestureDescription.getMaxGestureDuration();
    static final int  MAX_STROKES   = GestureDescription.getMaxStrokeCount();

    private static final long TAP_MS        = ViewConfiguration.getTapTimeout();        // 100
    private static final long LONG_PRESS_MS = ViewConfiguration.getLongPressTimeout() + 150L; // 650
    private static final long LIFT_MS       = 40L;

    /**
     * The only handle other components get. onServiceConnected() is the moment the
     * system has actually bound us and dispatchGesture() will work; onUnbind() /
     * onDestroy() is the moment it stops working, which can happen at any time
     * because the user can switch the toggle off or the process can be killed.
     */
    private static volatile TouchService sInstance;

    public static TouchService get() { return sInstance; }

    private final Handler main = new Handler(Looper.getMainLooper());
    private final ArrayDeque<Job> queue = new ArrayDeque<Job>();

    private boolean busy;                 // a gesture is in flight
    private StrokeDescription held;       // non-null while a pointer is held down
    private float heldX, heldY;
    private int screenW = 1080, screenH = 2400;

    // ------------------------------------------------------------- lifecycle

    @Override protected void onServiceConnected() {
        super.onServiceConnected();
        AccessibilityServiceInfo info = getServiceInfo();
        if (info != null) {
            // The capabilities (canPerformGestures / canRetrieveWindowContent) can only
            // come from the XML the user consented to. Plain flags can be added here.
            info.flags |= AccessibilityServiceInfo.FLAG_RETRIEVE_INTERACTIVE_WINDOWS
                        | AccessibilityServiceInfo.FLAG_REPORT_VIEW_IDS;
            if (Build.VERSION.SDK_INT >= 33) {
                info.flags |= AccessibilityServiceInfo.FLAG_INPUT_METHOD_EDITOR;
            }
            setServiceInfo(info);
        }
        measureScreen();
        sInstance = this;
        Log.i(TAG, "injector live: " + screenW + "x" + screenH
                + " maxStroke=" + MAX_STROKE_MS + "ms maxStrokes=" + MAX_STROKES);
    }

    @Override public boolean onUnbind(Intent intent) {
        sInstance = null;
        main.removeCallbacksAndMessages(null);
        queue.clear();
        busy = false;
        held = null;
        return super.onUnbind(intent);
    }

    @Override public void onDestroy() {
        sInstance = null;
        super.onDestroy();
    }

    @Override public void onConfigurationChanged(Configuration c) {
        super.onConfigurationChanged(c);
        measureScreen();   // gesture coordinates live in the display's CURRENT rotation
    }

    /** Declared typeWindowStateChanged only, so this is cheap. Nothing needs it. */
    @Override public void onAccessibilityEvent(AccessibilityEvent event) { }

    @Override public void onInterrupt() { }

    // ------------------------------------------------------------- the queue

    private interface Job {
        /** Built on the main thread, in order. Returning null skips the step. */
        GestureDescription build();
    }

    private void post(final Job job) {
        main.post(new Runnable() {
            @Override public void run() {
                if (queue.size() > 64) queue.poll();   // a stalled link must not grow forever
                queue.add(job);
                drain();
            }
        });
    }

    private void drain() {
        while (!busy && !queue.isEmpty()) {
            Job job = queue.poll();
            GestureDescription g;
            try {
                g = job.build();
            } catch (RuntimeException e) {
                // Negative path bounds, duration <= 0 or > 60s, >10 strokes,
                // continueStroke() on a stroke that was not willContinue, …
                Log.w(TAG, "gesture rejected: " + e);
                held = null;
                continue;
            }
            if (g == null) continue;
            busy = true;
            if (!dispatchGesture(g, callback, main)) {
                // Returns false when the service is not connected or the XML did not
                // declare canPerformGestures. No callback will ever arrive, so the
                // queue would wedge if we waited for one.
                Log.w(TAG, "dispatchGesture refused — not connected or canPerformGestures missing");
                busy = false;
                held = null;
                continue;
            }
            main.postDelayed(watchdog, endTime(g) + 1500L);
        }
    }

    private final GestureResultCallback callback = new GestureResultCallback() {
        @Override public void onCompleted(GestureDescription g) { finish(true); }
        @Override public void onCancelled(GestureDescription g) { finish(false); }
    };

    private void finish(boolean completed) {
        main.removeCallbacks(watchdog);
        busy = false;
        if (!completed) {
            // Cancelled means the pointer is gone (user touched the screen, another
            // service dispatched, the window went away). Any queued continuation of
            // it would throw, so drop the whole drag.
            held = null;
            queue.clear();
        }
        drain();
    }

    private final Runnable watchdog = new Runnable() {
        @Override public void run() {
            if (!busy) return;
            Log.w(TAG, "gesture callback never arrived — unwedging");
            busy = false;
            held = null;
            drain();
        }
    };

    private static long endTime(GestureDescription g) {
        long end = 0;
        for (int i = 0; i < g.getStrokeCount(); i++) {
            StrokeDescription s = g.getStroke(i);
            end = Math.max(end, s.getStartTime() + s.getDuration());
        }
        return end;
    }

    // ------------------------------------------------------------- gestures

    /** Short tap. A zero-length path is how the framework expresses "stay put". */
    public void tap(final float x, final float y) { tap(x, y, TAP_MS); }

    public void tap(final float x, final float y, final long ms) {
        post(new Job() {
            @Override public GestureDescription build() {
                return single(point(x, y), clamp(ms), false);
            }
        });
    }

    /** Hold past ViewConfiguration.getLongPressTimeout() so views fire onLongClick. */
    public void longPress(float x, float y) { tap(x, y, LONG_PRESS_MS); }

    public void doubleTap(final float x, final float y) {
        post(new Job() {
            @Override public GestureDescription build() {
                // Two strokes in one gesture, offset in time: one dispatch, so the
                // second tap cannot be cancelled by the first finishing.
                Path p = point(x, y);
                long gap = TAP_MS + 60L;
                return new GestureDescription.Builder()
                        .addStroke(new StrokeDescription(p, 0, TAP_MS))
                        .addStroke(new StrokeDescription(p, gap, TAP_MS))
                        .build();
            }
        });
    }

    /** One-shot swipe / fling. ms is the whole travel time: ~120 flings, ~500 scrolls. */
    public void swipe(final float x1, final float y1,
                      final float x2, final float y2, final long ms) {
        post(new Job() {
            @Override public GestureDescription build() {
                return single(line(x1, y1, x2, y2), clamp(ms), false);
            }
        });
    }

    /** Two fingers, one gesture. Pinch in with from > to, out with from < to. */
    public void pinch(final float cx, final float cy,
                      final float from, final float to, final long ms) {
        post(new Job() {
            @Override public GestureDescription build() {
                long d = clamp(ms);
                GestureDescription.Builder b = new GestureDescription.Builder();
                b.addStroke(new StrokeDescription(
                        line(cx - from, cy, cx - to, cy), 0, d));
                b.addStroke(new StrokeDescription(
                        line(cx + from, cy, cx + to, cy), 0, d));
                return b.build();
            }
        });
    }

    // ---- continuous drag -------------------------------------------------
    //
    // dragBegin / dragTo* / dragEnd map one-to-one onto the trackpad's
    // ACTION_DOWN / ACTION_MOVE / ACTION_UP. Each call is one dispatch; the
    // pointer survives between them because every segment but the last is
    // willContinue = true.

    /** Put a finger down and keep it down. */
    public void dragBegin(final float x, final float y) {
        post(new Job() {
            @Override public GestureDescription build() {
                held = null;                       // abandon any earlier stroke
                heldX = clampX(x);
                heldY = clampY(y);
                return single(point(heldX, heldY), 80L, true);
            }
        });
    }

    /** Move the held finger. Safe to call at trackpad frame rate — the queue serialises. */
    public void dragTo(final float x, final float y, final long ms) {
        post(new Job() {
            @Override public GestureDescription build() {
                if (held == null) return null;     // nothing is down; drop the segment
                float nx = clampX(x), ny = clampY(y);
                // A continuation MUST start where the previous segment ended.
                StrokeDescription s =
                        held.continueStroke(line(heldX, heldY, nx, ny), 0, clamp(ms), true);
                held = s;
                heldX = nx;
                heldY = ny;
                return new GestureDescription.Builder().addStroke(s).build();
            }
        });
    }

    /** Lift the finger. Without this the pointer stays down until something cancels it. */
    public void dragEnd() {
        post(new Job() {
            @Override public GestureDescription build() {
                if (held == null) return null;
                StrokeDescription s =
                        held.continueStroke(point(heldX, heldY), 0, LIFT_MS, false);
                held = null;
                return new GestureDescription.Builder().addStroke(s).build();
            }
        });
    }

    public boolean isDragging() { return held != null; }

    // ---- building blocks -------------------------------------------------

    /** heldX/heldY are set by the caller when willContinue is true. */
    private GestureDescription single(Path p, long ms, boolean willContinue) {
        StrokeDescription s = new StrokeDescription(p, 0, ms, willContinue);
        held = willContinue ? s : null;
        return new GestureDescription.Builder().addStroke(s).build();
    }

    /** Zero-length path: the framework treats it as a press that does not move. */
    private Path point(float x, float y) {
        Path p = new Path();
        p.moveTo(clampX(x), clampY(y));
        return p;
    }

    private Path line(float x1, float y1, float x2, float y2) {
        Path p = new Path();
        p.moveTo(clampX(x1), clampY(y1));
        p.lineTo(clampX(x2), clampY(y2));
        return p;
    }

    /** StrokeDescription throws on duration <= 0 or > getMaxGestureDuration(). */
    private static long clamp(long ms) {
        if (ms < 1) return 1;
        if (ms > MAX_STROKE_MS) return MAX_STROKE_MS;
        return ms;
    }

    /** Negative path bounds throw IllegalArgumentException; off-screen points do nothing. */
    private float clampX(float x) { return Math.max(0f, Math.min(x, screenW - 1f)); }
    private float clampY(float y) { return Math.max(0f, Math.min(y, screenH - 1f)); }

    private void measureScreen() {
        try {
            if (Build.VERSION.SDK_INT >= 30) {
                WindowManager wm = (WindowManager) getSystemService(WINDOW_SERVICE);
                Rect b = wm.getCurrentWindowMetrics().getBounds();
                screenW = b.width();
                screenH = b.height();
            } else {
                DisplayManager dm = (DisplayManager) getSystemService(DISPLAY_SERVICE);
                Display d = dm.getDisplay(Display.DEFAULT_DISPLAY);
                Point p = new Point();
                d.getRealSize(p);
                screenW = p.x;
                screenH = p.y;
            }
        } catch (Exception e) {
            Log.w(TAG, "could not measure display: " + e);
        }
    }

    public int width()  { return screenW; }
    public int height() { return screenH; }

    // ------------------------------------------------------------- text

    /**
     * Replace the focused editable's whole value.
     *
     * Limits, all of them real: the node must be editable (isEditable()), so this
     * does nothing on a WebView input, a Flutter/Unity surface, or a Compose field
     * that does not expose an editable node; it replaces the entire text instead of
     * typing, so TextWatchers see one big change and IME autocomplete never runs;
     * it cannot press Enter or Backspace; and some apps reject it on password fields.
     */
    public boolean setText(String text) {
        AccessibilityNodeInfo n = findFocus(AccessibilityNodeInfo.FOCUS_INPUT);
        if (n == null) return false;
        try {
            if (!n.isEditable()) return false;
            Bundle args = new Bundle();
            args.putCharSequence(
                    AccessibilityNodeInfo.ACTION_ARGUMENT_SET_TEXT_CHARSEQUENCE, text);
            return n.performAction(AccessibilityNodeInfo.ACTION_SET_TEXT, args);
        } finally {
            if (Build.VERSION.SDK_INT < 33) n.recycle();
        }
    }

    /** ACTION_SET_TEXT has no "append", so read the value back and rewrite it. */
    public boolean appendText(String text) {
        AccessibilityNodeInfo n = findFocus(AccessibilityNodeInfo.FOCUS_INPUT);
        if (n == null) return false;
        try {
            if (!n.isEditable()) return false;
            CharSequence cur = n.getText();
            String base = cur == null ? "" : cur.toString();
            Bundle args = new Bundle();
            args.putCharSequence(
                    AccessibilityNodeInfo.ACTION_ARGUMENT_SET_TEXT_CHARSEQUENCE, base + text);
            return n.performAction(AccessibilityNodeInfo.ACTION_SET_TEXT, args);
        } finally {
            if (Build.VERSION.SDK_INT < 33) n.recycle();
        }
    }

    /**
     * Type at the cursor through the accessibility IME connection (API 33+, needs
     * FLAG_INPUT_METHOD_EDITOR). This is the only way to insert at the caret, send
     * Enter/Backspace, or type into fields where ACTION_SET_TEXT fails.
     *
     * The connection exists only while an editor has input started — i.e. a text
     * field is focused AND the soft keyboard is attached. So: tap the field with
     * dispatchGesture() first, give it a beat, then call this.
     */
    @Override public InputMethod onCreateInputMethod() {
        return new InputMethod(this);
    }

    public boolean commitText(String text) {
        InputMethod.AccessibilityInputConnection ic = inputConnection();
        if (ic == null) return false;
        ic.commitText(text, 1, null);
        return true;
    }

    public boolean sendKey(int keyCode) {
        InputMethod.AccessibilityInputConnection ic = inputConnection();
        if (ic == null) return false;
        long t = SystemClock.uptimeMillis();
        ic.sendKeyEvent(new KeyEvent(t, t, KeyEvent.ACTION_DOWN, keyCode, 0));
        ic.sendKeyEvent(new KeyEvent(t, t, KeyEvent.ACTION_UP, keyCode, 0));
        return true;
    }

    public boolean deleteBackward(int chars) {
        InputMethod.AccessibilityInputConnection ic = inputConnection();
        if (ic == null) return false;
        ic.deleteSurroundingText(chars, 0);
        return true;
    }

    private InputMethod.AccessibilityInputConnection inputConnection() {
        if (Build.VERSION.SDK_INT < 33) return null;
        InputMethod im = getInputMethod();
        if (im == null || !im.getCurrentInputStarted()) return null;
        return im.getCurrentInputConnection();
    }

    /** IME first, ACTION_SET_TEXT second. Returns false when neither route worked. */
    public boolean type(String text) {
        return commitText(text) || appendText(text);
    }

    public boolean enter() {
        return sendKey(KeyEvent.KEYCODE_ENTER);
    }

    public boolean backspace() {
        if (deleteBackward(1)) return true;
        AccessibilityNodeInfo n = findFocus(AccessibilityNodeInfo.FOCUS_INPUT);
        if (n == null) return false;
        try {
            CharSequence cur = n.getText();
            if (!n.isEditable() || cur == null || cur.length() == 0) return false;
            Bundle args = new Bundle();
            args.putCharSequence(AccessibilityNodeInfo.ACTION_ARGUMENT_SET_TEXT_CHARSEQUENCE,
                    cur.subSequence(0, cur.length() - 1).toString());
            return n.performAction(AccessibilityNodeInfo.ACTION_SET_TEXT, args);
        } finally {
            if (Build.VERSION.SDK_INT < 33) n.recycle();
        }
    }

    // ------------------------------------------------------------- wire protocol

    /**
     * Called straight from the socket thread in MainActivity. Everything that
     * touches gesture state is funnelled onto the main looper by post(), so this
     * needs no locking of its own.
     *
     * Coordinates are absolute display pixels in the current rotation.
     *   T x y            tap
     *   L x y            long press
     *   DT x y           double tap
     *   S x1 y1 x2 y2 ms swipe
     *   P cx cy r1 r2 ms pinch
     *   DB x y           drag begin (finger down, stays down)
     *   DM x y ms        drag move
     *   DU               drag end (finger up)
     *   K text           type at the cursor
     *   SET text         replace the focused field
     *   KEY enter|back   editor keys
     *   G back|home|recents|notifications|quick|power|lock|shot|shade
     *
     * @return false when the service is not running, so the caller can tell the
     *         Mac to show "grant accessibility" instead of silently dropping input.
     */
    public static boolean exec(String line) {
        TouchService s = sInstance;
        if (s == null || line == null) return false;
        String[] a = line.trim().split("\\s+", 7);
        if (a.length == 0 || a[0].isEmpty()) return false;
        try {
            switch (a[0]) {
                case "T":   s.tap(f(a, 1), f(a, 2)); return true;
                case "L":   s.longPress(f(a, 1), f(a, 2)); return true;
                case "DT":  s.doubleTap(f(a, 1), f(a, 2)); return true;
                case "S":   s.swipe(f(a, 1), f(a, 2), f(a, 3), f(a, 4), l(a, 5, 220)); return true;
                case "P":   s.pinch(f(a, 1), f(a, 2), f(a, 3), f(a, 4), l(a, 5, 400)); return true;
                case "DB":  s.dragBegin(f(a, 1), f(a, 2)); return true;
                case "DM":  s.dragTo(f(a, 1), f(a, 2), l(a, 3, 24)); return true;
                case "DU":  s.dragEnd(); return true;
                case "K":   return s.type(rest(line, 1));
                case "SET": return s.setText(rest(line, 1));
                case "KEY":
                    if (a.length > 1 && "enter".equals(a[1])) return s.enter();
                    if (a.length > 1 && "back".equals(a[1]))  return s.backspace();
                    return false;
                case "G":
                    if (a.length < 2) return false;
                    switch (a[1]) {

            cut = t.indexOf(' ', cut + 1);
            if (cut < 0) return "";
            while (cut + 1 < t.length() && t.charAt(cut + 1) == ' ') cut++;
        }
        return t.substring(cut + 1).replace("\\n", "\n");
```

# 7. Handing gestures from the socket thread to the service — static reference, not binding

You cannot bind your own `AccessibilityService`: `AccessibilityService.onBind()` is `final` and returns the `IAccessibilityServiceClient` binder for system_server. A `bindService()` from your own process gets you nothing usable, and `android:permission="BIND_ACCESSIBILITY_SERVICE"` means your app (which does not hold that signature permission) cannot bind it anyway. A static `volatile` reference published in `onServiceConnected()` and cleared in `onUnbind()`/`onDestroy()` is the correct mechanism — `onServiceConnected()` is precisely the "now dispatch works" signal.

The leak concern that normally rules out static Context references does not apply: the system owns this Service's lifetime, and the reference is nulled on unbind. Two rules make it safe: the field is `volatile` and every call site re-reads it (`TouchService.exec` snapshots `sInstance` once), and no caller touches gesture state directly — `post()` marshals every job onto the service's own main looper, so the socket reader thread never races the `queue`/`held`/`busy` triple.

# 8. The constraints that actually bite

**Serialisation is mandatory, not an optimisation.** `dispatchGesture()` cancels any gesture in flight — including the user's real finger and other services' gestures. Fire two swipes back to back without waiting and you get one swipe plus an `onCancelled`. The queue plus the `busy` flag is the whole reason this works at trackpad frame rate.

**`dispatchGesture()` returning false means no callback, ever.** It returns false when the service is not connected or the XML omitted `canPerformGestures`. Code that sets `busy = true` and waits for a callback wedges permanently. The `!ok` branch resets state immediately, and the `watchdog` (gesture duration + 1.5 s) covers a lost callback.

**Stroke limits, read from the framework, not hard-coded:** `GestureDescription.getMaxGestureDuration()` = 60000 ms, `getMaxStrokeCount()` = 10. `StrokeDescription`'s constructor throws `IllegalArgumentException` on duration ≤ 0, duration > 60 s, negative path bounds, or an empty path; `Builder.addStroke()` throws once a stroke would end past 60 s or an 11th stroke is added. Hence `clamp()`, `clampX/clampY`, and the `catch (RuntimeException)` around `job.build()`. A drag longer than 60 s is not one stroke — it is a chain of continued segments, which this design produces naturally.

**`willContinue` semantics.** A stroke with `willContinue = true` keeps its pointer down after the gesture completes. Its continuation must come from `thatStroke.continueStroke(path, start, dur, willContinue)` — calling it on a stroke that was not `willContinue` throws `IllegalStateException` — and the continuation's path must start at the previous path's end point. Critically, dispatch the continuation **after** the previous segment's `onCompleted()`: the gesture completes while the finger stays down, so there is nothing in flight to cancel. Dispatch early and you cancel your own drag. Always terminate with `willContinue = false`, otherwise the pointer stays down until a real touch or another dispatch cancels it — which looks to the user like a stuck finger.

**A zero-length path is the framework's "tap".** `point()` does `moveTo` only; the platform treats a path with no length as a press that does not move, so a long duration on a zero-length path is a long-press. `doubleTap()` uses two time-offset strokes in one `GestureDescription` rather than two dispatches, because the second dispatch would otherwise race the first's completion.

**Coordinates are absolute display pixels in the current rotation.** Off-screen points dispatch fine and do nothing; negative bounds throw. Re-measure on `onConfigurationChanged`. On API 30+, `WindowManager.getCurrentWindowMetrics().getBounds()` is the correct source; below that, `Display.getRealSize()`.

**Text.** `ACTION_SET_TEXT` is cheap but narrow: the node must report `isEditable()`, it replaces the entire value (no caret insert, no append — hence `appendText()` rewriting the whole string), it bypasses the IME so autocomplete and per-character `TextWatcher` logic never run, and it cannot produce Enter or Backspace. It fails outright on WebView inputs, Flutter/Unity surfaces, and Compose fields that do not expose an editable node. The real fix on API 36 is the accessibility IME: `FLAG_INPUT_METHOD_EDITOR` (API 33+, both in the XML and OR'd in at runtime) gives `getInputMethod().getCurrentInputConnection()` with `commitText`, `sendKeyEvent`, `deleteSurroundingText`, `performEditorAction`. It is live only while an editor has input started, so the sequence is: tap the field with a gesture, let the keyboard attach, then `commitText`. `type()` tries the IME and falls back to `ACTION_SET_TEXT`.

**Enablement has three different answers, and they are not interchangeable.** `Settings.Secure.ENABLED_ACCESSIBILITY_SERVICES` reflects the toggle (flips first, no permission needed, but compare against *both* flatten forms). `AccessibilityManager.getEnabledAccessibilityServiceList()` reflects what the system bound — and `AccessibilityServiceInfo.getId()` is a *short* flattened name, so the common `getId().equals(cn.flattenToString())` check silently never matches; compare the `ResolveInfo.serviceInfo` instead. Only `TouchService.get() != null` proves injection works this instant.

**Android 13+ restricted settings.** If this APK is installed by tapping it in a file manager, Settings greys out the accessibility toggle behind "Restricted setting" until the user does App info → ⋮ → Allow restricted settings. `adb install` is exempt, so the existing build-and-push flow avoids it — but a hand-copied APK will look broken for a reason that has nothing to do with this code.

**Keyguard.** Gestures do reach the lock screen, but the PIN/password entry excludes itself from capture and does not expose usable nodes, so remote unlock is not reachable this way — the same wall already recorded for the scrcpy path in this project.
